风格简介 / Introduction

法国南部普罗旺斯地区在干暖、强光、贫瘠土壤的气候下,几个世纪累积出的花园模式——以耐旱的芳香草本(薰衣草、迷迭香、百里香)为主角,石头矮墙、橄榄树、葡萄藤架作为骨架。它不像英式乡村那样靠"花量"取胜,而是靠"香气 + 阳光 + 石头"的三件套。

核心气质
慢、暖、芳香、有阳光感。比英式乡村更克制,比地中海更有家庭感——它是"乡村度假"的视觉标准之一。
起源 / 背景
由法国南部普罗旺斯地区(Vaucluse, Bouches-du-Rhône)几个世纪的农庄生活演化而来,20 世纪后期通过 Peter Mayle《山居岁月》《普罗旺斯的一年》等书籍被全球化,成为"南欧乡村度假"的代名词。
室内衔接
与法式乡村、Vintage 法式、地中海、自然乡村、Bohemian 室内完美衔接;与现代极简、新中式、Loft 室内冲突——它的"暖与慢"与现代极简的"冷与快"是对立的。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
大片薰衣草丛——成排或成片的薰衣草是普罗旺斯花园的图腾——通常被修剪成圆球形或矮丘状,深紫色与银灰叶面在强光下极具识别度。
02
石头矮墙(dry-stone wall)——不抹灰的干砌石墙,常作为台地分隔、花池围合——是普罗旺斯山地坡地花园的标志性结构。
03
橄榄 + 柏树组合——单株或几株橄榄(深绿圆冠)+ 高耸的意大利柏树(深绿火炬形)——是与英式乡村花园最大的乔木区别。
04
赤陶罐与铸铁桌椅——大量手工赤陶罐种着香草、天竺葵,蓝色或灰色铸铁圆桌椅在橄榄树下——构成"普罗旺斯下午"的经典画面。
05
葡萄藤架(pergola)——木质或铸铁的葡萄藤架,夏季提供遮荫,秋季果实累累——既是建筑元素也是户外用餐的"天然顶棚"。
— 05

核心特征 / Core Features

空间结构
露台 + 葡萄藤架 + 香草花池 + 橄榄树孤植 + 石头矮墙 + 户外餐厨区。常顺山地地形分层布置,每一层都是一个独立"露台"——这是与英式乡村平地花园最大的空间区别。
动线 / 视线
沿地形蜿蜒,常出现石阶 + 砾石路 + 拱门组合。视线追求"远山 + 葡萄园 + 薰衣草田"的层次,常以远处的山丘或村落作为画面消失点。
植物语言
植物气质"耐旱 + 芳香 + 银灰"是核心。植物以芳香草本与耐旱灌木为主,叶面多为银灰色(反射强光),花色集中在紫、白、薰衣草色——形成与英式乡村完全不同的"地中海植物群"。
代表植物薰衣草 · 迷迭香 · 百里香 · 鼠尾草 · 橄榄 · 意大利柏 · 月桂 · 葡萄
水景关系
水景极少且实用——常见石砌水盆(养鸽子或洗手用)、井、小型矮喷泉。水的功能是降温与生活,而不是装饰。没有水景也是普罗旺斯花园的常见状态。
光影氛围
强烈日照 + 葡萄藤架的斑驳光影是核心氛围——夏日午后的阳光把石头矮墙烤得发烫,葡萄叶投下精致的影子。普罗旺斯的"金色光线"(黄昏)被全世界摄影师追逐——是花园最美的时刻。
色彩系统
薰衣草紫 + 橄榄银绿 + 石头暖灰 + 赤陶橙 + 葡萄藤深绿。比英式乡村更克制(色相少),比地中海更柔和(饱和度低)。普罗旺斯的"紫 + 银 + 暖灰"是它独有的色彩标签。
材料系统
干砌石墙、石板地、赤陶砖、木质葡萄藤架、铸铁桌椅、手工陶罐、麻布、橄榄木家具——所有材料都带着"百年农庄生活"的痕迹。新材料几乎不入流。
休闲与活动
主要活动葡萄藤下午餐 · 摘香草做菜 · 户外烧烤 · 朋友聚会 · 远眺薰衣草田
推荐场景夏日午餐 · 6 月薰衣草盛开 · 9 月葡萄收获 · 黄昏酒会
生活方式"慢生活"的具象化 · 重视家庭与朋友聚会 · 园艺与厨房深度结合(香草直接采摘下锅)

相关风格 / Related Styles

用于横向判断与边界划分
地中海庭院 Mediterranean Courtyard
相似:同源地中海气候,共享橄榄、葡萄、香草、白墙基因。
差异:地中海庭院更"度假露台"化(海景、户外餐桌为主,装饰偏多);普罗旺斯花园更"乡村农庄"化(山地坡地、葡萄园、花池为主,生活感更强)。一个面向海,一个面向山。
英式乡村花园 English Cottage Garden
相似:都是欧洲乡村花园,都强调家庭日常感。
差异:英式乡村湿润、繁盛、玫瑰为王;普罗旺斯干暖、克制、薰衣草为王。两个气候差异决定了完全不同的植物语言与维护节奏——英式要每周打理,普罗旺斯耐放得多。
托斯卡纳庭院 Tuscan Garden
相似:都是南欧山地乡村花园,共享橄榄 + 柏树 + 葡萄藤架基因。
差异:托斯卡纳保留意大利文艺复兴庄园基因(轴线、修剪绿篱、雕塑),更有"贵族农庄"感;普罗旺斯更纯农庄(松散、无修剪、薰衣草为主),更日常化。
法式乡村花园 French Country Garden
相似:同源法国乡村,有家庭花园基因。
差异:法式乡村保留几何骨架(轴线、绿篱),里面填乡村花卉;普罗旺斯更松散,几乎无几何感。气候上法式乡村以法国北部/中部为主,普罗旺斯专指南部地中海气候区。
— 07

适配性 / Suitability

SUITABLE SPACE · 适合空间
中庭院 大庭院 坡地花园 乡村别墅 山地住宅
最理想是有坡地或起伏地形的庭院,200–600 ㎡。能撑起"露台 + 葡萄藤架 + 花池"的层次,又不至于显空旷。平地也可以,但需要主动制造高差。
SUITABLE CLIMATE · 适合气候
地中海气候 干暖 阳光充足 温暖大陆性
必须是干暖、阳光充足的气候——薰衣草、迷迭香、橄榄都依赖这种气候。中国仅云南、新疆、华南部分干燥地区能真正适配。华东、华中梅雨季薰衣草易烂根,北方冬季橄榄无法越冬——做出来气质会失真。
MAINTENANCE · 维护难度
中低
植物本身耐旱、低维护——这是普罗旺斯的核心红利。每年的主要工作就是修剪薰衣草球形、葡萄藤季节性修剪、清理橄榄落叶。比英式乡村低很多,适合"不愿天天打理"的家庭。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料干砌石墙 · 石板地 · 赤陶 · 木葡萄藤架 · 铸铁桌椅 · 手工陶罐
核心植物薰衣草 · 迷迭香 · 百里香 · 鼠尾草 · 橄榄 · 意大利柏 · 葡萄
UNFIT SCENARIOS · 不适配场景
湿润多雨地区 寒冷气候 小尺度内院 现代极简室内 "度假感为先"
华东、华南湿润气候薰衣草、迷迭香易烂根,几年内会渐渐枯死;寒冷气候橄榄、意大利柏无法越冬;小内院容不下葡萄藤架与坡地花池;现代极简室内与普罗旺斯的"暖与慢"气质冲突;追求"度假打卡"的家庭谨慎选用——普罗旺斯本质是慢生活,需要时间沉浸,不是来住几天就能享受的风格。

代表案例与来源 / Reference Projects & Sources

A 权威 · B 优秀参考 · C 灵感印象
A
瓦朗索勒高原 (Plateau de Valensole) 薰衣草田
几个世纪累积 · 普罗旺斯传统
普罗旺斯花园的"视觉源头"。整片高原在 6–7 月被薰衣草覆盖,与橄榄树、石头农舍、远山构成的"普罗旺斯三件套"画面——是全世界对普罗旺斯的视觉印象起点。
标杆案例
A
塞南克修道院 (Abbaye de Sénanque) 庭院
12 世纪 · 西多会修道院
普罗旺斯花园的"朝圣地"——石砌修道院前的薰衣草田,简洁的几何阵列与背后中世纪建筑形成永恒画面。是几乎所有普罗旺斯摄影集的封面。
标杆案例
A
La Louve · Bonnieux
Nicole de Vésian · 1990s
现代普罗旺斯花园的设计师典范。Hermès 设计师 Nicole de Vésian 把自己的私人花园做成了"普罗旺斯极简版"——把薰衣草、迷迭香、橄榄修剪成精确的球形与几何形,影响了整整一代景观设计师。
标杆案例
B
普罗旺斯各乡村高端 B&B 庭院
Gordes / Lourmarin / Roussillon 等村落
普罗旺斯地区的高品质 B&B 是"当代普罗旺斯花园"的最佳实景样本——把传统农庄花园与现代度假体验融合。
落地案例
B
新疆 伊犁 · 国内薰衣草观光地
伊犁地区
中国本土最接近普罗旺斯气候的地区。伊犁的薰衣草种植与农庄环境,可作为"中国版普罗旺斯花园"的气候参考——也提示了普罗旺斯气候在中国的稀缺性。

备注说明
"普罗旺斯风"在中国常被简化为"种点薰衣草 + 紫白配色"——这是失败的本土化。真正的普罗旺斯花园核心是"耐旱植物群 + 干砌石墙 + 葡萄藤架 + 农庄生活方式"四件套,缺一不成立。判断标准:看是否有真正干砌的石墙,看薰衣草是否被修剪成清晰的球形(而非自由生长的杂草)。
