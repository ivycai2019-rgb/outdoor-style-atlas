植物专题库

Plant Library

按"植物专题 + 生态"组织的室外植栽配置——玫瑰花园、花境、香草园、砾石花园、雨水花园、耐旱植物等。 它回答的不是"这是什么风格",而是"这一片植物群该怎么组织"——是 4 库系统里"从植物出发"的入口。

建设中:本库目前已完成总体分类与分析框架,玫瑰花园等首批专题页已有 md 草稿。后续每个专题都会展开为独立页面,包含植物选择、配置方式、维护要点、生态价值等完整分析。

分析框架 / Framework

每个专题页的标准研究维度
  • 🌱 植物选择(代表 / 品种 / 习性 / 生态)
  • 📐 配置方式(布局 / 层次 / 色彩 / 空间)
  • 🌤️ 气候适应(温度 / 湿度 / 光照 / 土壤)
  • 🛠️ 维护要点(浇水 / 施肥 / 修剪 / 病虫)
  • 💰 成本分析(种植 / 维护 / 生命周期)
  • 🎨 设计应用(风格适配 / 空间 / 季节 / 视觉)
  • 🔬 生态价值(多样性 / 环境 / 可持续 / 教育)
  • 🔗 跨库链接(适合风格 / 对应空间 / 配套场景)
