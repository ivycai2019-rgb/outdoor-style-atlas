风格简介 / Introduction

美式后院庭院是 20 世纪美国郊区文化的"视觉宪法"——二战后郊区化运动让每个美国家庭都有自己的后院,这个后院被设计为"家庭社交核心":大草坪 + 木栅栏 + 木质露台 + 烧烤架,周末就是家人朋友的聚会场。它不追求花园美学,追求"被实际使用"。

核心气质
宽敞、实用、家庭感、社交友好。比英式乡村"更口语化",比现代极简"更日常化"——它是为"真实家庭生活"而设计的庭院。
起源 / 背景
二战后美国郊区化(1945–1970)塑造了"带后院的独栋住宅"作为美国梦标志。"BBQ 烧烤文化"与"家庭周末"共同塑造了后院庭院的功能定位。
室内衔接
与美式古典、美式乡村、现代美式、Craftsman 工艺美术风格室内完美衔接;与新中式、欧式古典、地中海室内冲突——气质上太"美式日常"。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
大草坪占地表 50%+——美式后院的灵魂是「可以打滚的草坪」,常是早熟禾或百慕大草。
02
木质露台(deck)——压力处理木做的露台从室内推开门就到,是「室内外连续」的核心。
03
烧烤架/户外厨房——美式后院必备,常在 deck 一角或独立小屋,是「BBQ 文化」的物理表达。
04
木栅栏围合——白色或防腐色的木栅,1.5–2m 高,提供隐私又保持邻里感。
05
大乔木遮阴——枫树、橡树等大乔木提供「斑驳树荫」,是美式后院的招牌画面。
— 05

核心特征 / Core Features

空间结构
大草坪占主体(50% 以上)+ 木质露台(deck) + 烧烤角 + 边缘花境 + 树荫区。常见标准布局:"从室内推开门 → 木露台 → 草坪 → 边缘灌木" 的三段过渡。
动线 / 视线
直接 + 开放——动线追求"从客厅到草坪无障碍"。视线开阔,常以木栅栏作为边界,栅栏外可以是邻居或景观。
植物语言
植物气质"草坪 + 大乔木遮阴 + 边缘混合花境"三段结构。植物以"本土易养"为标准,允许花卉与野草混植——比英式乡村更松散。
代表植物草坪(早熟禾/百慕大草) · 大乔木(枫树/橡树) · 多年生花境(雏菊/紫锥菊) · 灌木绿篱(常春藤/绣球)
水景关系
水景较少且功能化——常见小型泳池(美国家庭后院的"奢侈标配")或儿童充气泳池。装饰水景几乎不见。
光影氛围
大乔木投下的"斑驳树荫"是经典氛围——是美式后院的招牌画面。夜景以串灯 + 烧烤架火光 + 木露台地灯为主,温馨而非戏剧化。
色彩系统
草坪深绿 + 木栅褐 + 边缘花境季节色 + 砖红色烧烤架。整体暖且有"郊区感"——不是设计师的"极简白",而是"使用过的暖"。
材料系统
压力处理木(deck 标配)、木栅栏、红砖(烧烤架/小径)、混凝土、再生木家具。所有材料都"耐用 + 易买 + 易换"——美式实用主义。
休闲与活动
主要活动BBQ 烧烤 · 家庭聚会 · 儿童游乐 · 宠物活动 · 户外用餐 · 草坪游戏
推荐场景周末烧烤 · 国庆/独立日聚会 · 生日派对 · 儿童跑跳 · 黄昏闲聊
生活方式有孩子的家庭 · 重视社交与家庭活动 · 节奏轻松 · 强调"家就是港湾"

适配性 / Suitability

SUITABLE SPACE · 适合空间
大后院 郊区独栋 联排别墅后院 独立庄园
必须有大尺度后院——最少 200 ㎡,理想 500 ㎡+。需要能撑起"大草坪 + 木露台 + 烧烤区"三件套。小尺度做不出气质。
SUITABLE CLIMATE · 适合气候
温带 温暖大陆性 四季分明 湿润
气候适应性广——草坪文化在欧美温带最成熟,但"草坪"在中国湿热南方维护困难(易病害)、干旱地区耗水大。最适合华北/华中/东北气候。
MAINTENANCE · 维护难度
中高
维护负担主要在草坪——每周修剪、每月施肥、季节性补播、夏季浇水。木质露台需 5–7 年防腐处理。"剪草坪"几乎是美国家庭周末的标准家务。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料压力处理木 · 红砖 · 木栅栏 · 混凝土 · 再生木家具
核心植物草坪 · 大乔木(枫/橡)· 多年生花境 · 灌木绿篱
UNFIT SCENARIOS · 不适配场景
小尺度 东方含蓄室内 无烧烤习惯 单身公寓
小尺度撑不起大草坪;新中式或欧式古典室内严重冲突;"没有 BBQ 烧烤习惯的家庭"做出来后会发现"烧烤架 1 年用 1 次"——白白占地;单身或丁克家庭做出来过于"家庭气质"。

相关风格 / Related Styles

美式乡村花园American Cottage Garden
相似:同体系兄弟,都体现美式日常文化。
差异:美式后院"草坪 + 烧烤 + 实用";美式乡村"花境 + 浪漫 + 多年生植物",更受英式乡村影响。后院偏"男性化的家务",乡村偏"女性化的园艺"。
英式乡村花园English Cottage Garden
相似:都为家庭日常服务。
差异:英式乡村"花是主角"(花境密集,色彩饱和);美式后院"草坪是主角"(花卉只在边缘)。两个文化对"家庭花园"的理解完全不同——英国人种花,美国人剪草。
露台度假花园Terrace Resort Garden
相似:都强调户外社交与休闲。
差异:露台度假"商业化奢侈感"(无边泳池/精品酒店感);美式后院"日常家庭感"(草坪 + BBQ + 家庭活动)。一个是"度假体验",一个是"每日生活"。
农庄庭园Farmhouse Garden
相似:都"反精致 + 重实用"。
差异:农庄庭园"种 + 养 + 收"(食物产出为核心);美式后院"玩 + 聚 + 休"(社交休闲为核心)。两者都"实用",但实用方向不同。
