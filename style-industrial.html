风格简介 / Introduction

工业风庭院是 1990 年代后都市改造潮流下发展出的庭院语言——清水混凝土、耐候钢、裸露管线、金属网架取代传统石材与木材,植物以观赏草、苔藓、单株姿态树为主,常用于Loft 公寓、改造厂房、设计酒店的户外空间。

核心气质
硬朗、克制、有工业纹理与都市感。比极简景观更粗粝(材料表面不抛光),比现代庭院更冷(几乎无暖色)。
起源 / 背景
源于 1970–80 年代纽约 SoHo、伦敦 East End 的厂房 Loft 改造潮,21 世纪在中国 798、北京 751、上海西岸等再生项目中本土化。代表案例:High Line(纽约 2009)、Olympic Sculpture Park(西雅图)、Tate Modern 周边景观。
室内衔接
与 Industrial Loft、Brutalist、Brooklyn 工业室内完美衔接;与英式乡村、地中海、巴厘风、新中式严重冲突。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
裸露混凝土与红砖墙——保留工业建筑原有的墙体,不抹灰、不粉刷,直接作为庭院围墙或背景。
02
生锈钢板(corten)——耐候钢有意保留锈迹,作为花池、围栏或景观元素——是工业风最具识别度的材料。
03
旧管道、钢梁、铁艺再用——原工业建筑的管道与结构被保留,成为景观「骨架」,有「被改造过」的痕迹。
04
大叶植物与硬质对比——龟背竹、芭蕉、藤本植物在裸混凝土前生长,植物的「生命感」与材料的「死硬」形成强对比。
05
裸灯泡与黄铜灯具——夜间用爱迪生灯泡 + 黄铜灯具,营造 loft 室内一样的氛围。
— 05

核心特征 / Core Features

空间结构
常常依托既有工业遗产——旧厂房院子、废弃停车场、城市边角空间。也可以"新建模拟"——但必须刻意做出粗糙感,平整光鲜的工业风一定失败。
动线 / 视线
直线、几何、不修饰转角。视线追求"结构暴露"——管道、梁柱、钢架成为景观元素而非要遮蔽的对象。
植物语言
植物气质植物作为"硬质材料的反差"出现——大叶植物在钢板墙前显得格外有生命力,藤本植物攀爬在生锈管道上构成"自然 vs 工业"的对比。
代表植物龟背竹 · 大叶榕 · 藤本植物(常春藤/绿萝) · 多肉 · 草本观赏草
水景关系
水景较少,且形态"管道感"——出水口是裸露铁管、水池是水泥工业槽。完全拒绝任何"装饰水景"。
光影氛围
钢梁与混凝土在阳光下投下硬边阴影——是工业风最有代表性的光影画面。夜景常用裸灯泡 + 黄铜灯具,氛围接近 loft 室内。
色彩系统
混凝土灰 + 红砖橙 + 锈钢红褐 + 深绿(植物)+ 黑(铁艺)。比现代庭院更"暖且斑驳",饱和度极低但有温度。
材料系统
裸露混凝土、红砖、生锈钢板(corten)、黑铁、黄铜、再生木——所有材料都保留"使用过"的痕迹。新材料做旧是常用手段。
休闲与活动
主要活动都市社交 · 艺术展示 · 工作室外间 · 朋友聚会 · 商业酒会
推荐场景夜间酒会 · 摄影场景 · 设计师工作休息 · 周末市集
生活方式都市单身 / 设计师 / 艺术家 · 节奏快 · 重视"有个性的不完美"
— 06

适配性 / Suitability

SUITABLE SPACE · 适合空间
旧厂房院 城市内院 下沉院 商业酒店 设计师工作室
最理想是有"工业历史"的空间——废弃厂房、旧仓库、地下室。新建项目也可以做,但需要刻意制造粗糙感。
SUITABLE CLIMATE · 适合气候
城市气候 温带 温暖大陆性
气候适应性广。最适合温带与城市气候——锈钢、混凝土、红砖在四季都耐用。湿热地区需注意钢材防锈过度(变成"真锈"而非"设计感的锈")。
MAINTENANCE · 维护难度
低
维护负担低——硬质材料耐用,植物少。主要负担在耐候钢的"受控生锈"(不能锈穿)与垂直绿化的浇水系统。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料裸混凝土 · 红砖 · 生锈钢板(corten)· 黑铁 · 黄铜
核心植物龟背竹 · 大叶榕 · 藤本植物 · 多肉 · 观赏草
UNFIT SCENARIOS · 不适配场景
古典建筑 儿童活动 想要"温馨家庭感" 无工业历史背景
与古典建筑严重冲突;儿童活动主导的家庭会感到"过冷";追求温馨家庭感的家庭不要做——工业风本质是都市单身 + 设计师审美;无任何工业历史背景的新建项目容易做成"装饰主义版本",失去本质。

代表案例与来源 / Reference Projects & Sources

A
High Line · 纽约
James Corner Field Operations + Diller Scofidio + Renfro · 2009
工业风景观的图腾。废弃高架铁路改造为带状公园——保留铁轨、混凝土结构,加入"被设计的野草"——是当代"工业风 + 自然主义"的开创性融合。
标杆案例
A
Duisburg Nord Landschaftspark · 德国
Peter Latz · 1990s
把整座废弃钢铁厂改造为公共公园——保留高炉、管道、轨道,让它们与植物共存。"工业遗产景观化"的教科书级案例。
标杆案例
B
北京 · 798 艺术区
原电子工业部 718 联合厂区 · 1950s 始建
中国工业风景观的代表性实景。原电子工厂区改造,保留 Bauhaus 风格厂房与院落,户外空间散布工业雕塑、原管道、艺术装置。
落地案例
B
上海 · M50 创意园 / 西岸艺术区
原纺织厂 / 老码头改造
上海工业风改造的代表项目——把废弃工厂、码头作为艺术与设计园区,户外空间保留原有工业骨架。

备注说明
"工业风"在中国市场被严重稀释——很多"工业风餐厅"只是"刷黑色油漆 + 露管线 + 爱迪生灯泡"的浅层模仿。真正的工业风庭院核心是"真实的工业遗产 + 受控的废弃感 + 植物作为生命对比"三件套。

相关风格 / Related Styles

都市微型花园Urban Pocket Garden
相似:同属工业与都市体系,共享城市感。
差异:工业风必须有"工业遗产感"(裸混凝土/锈钢/红砖);都市微型花园更"日常"(强调小尺度与功能性,材料更轻),没有工业感包袱。
现代庭院Modern Garden
相似:都使用混凝土与几何骨架。
差异:现代庭院追求"精致清洁感"(清水混凝土光滑,边线锋利);工业风追求"粗糙改造感"(混凝土有缝隙,材料有锈迹)。一个是"新",一个是"被使用过的旧"。
极简景观Minimal Landscape
相似:都用大量混凝土与硬质材料。
差异:极简景观是"艺术作品式洁净"(精确施工、单一品种植物);工业风是"再利用式粗犷"(混搭材料、植物充满野趣)。气质完全相反。
自然主义庭院Naturalistic Garden
相似:都能与工业元素融合(High Line 就是两者合体)。
差异:自然主义把"野草本"作为主体,工业元素是配角;工业风把"工业遗产"作为主体,植物是配角。谁是主谁是辅决定了两种风格的归属。
