户外用餐

Outdoor Dining

把"吃饭"从室内餐桌搬到户外阳光下——它不是"室内餐厅的延伸",而是独立的生活方式。地中海、托斯卡纳、英式乡村庭院的灵魂都来自这件事。

家庭日常 社交 餐桌为核心 3 季使用
— 01

👥使用人群 / Users

目标用户

  • 家庭用户:享受天伦之乐的日常晚餐
  • 社交达人:喜欢邀请朋友的聚会型家庭
  • 美食爱好者:享受烹饪与品尝过程
  • 度假体验者:追求度假感生活方式的家庭

人数与场景

  • 小型聚餐(2–6 人):日常家庭用餐
  • 中型聚会(6–12 人):周末家庭/朋友聚会
  • 大型宴会(12+ 人):节庆、生日、家庭派对

使用频率与时段

  • 春夏秋三季为主,冬季仅暖地或暖光设备齐全时使用
  • 晚餐(18:00–22:00)是最典型场景:营造浪漫与放松氛围
  • 周末早午餐与下午茶是补充场景
— 02

📐空间需求 / Spatial

面积要求

  • 小型:10–20 ㎡(2–4 人)
  • 中型:20–40 ㎡(4–8 人)
  • 大型:40 ㎡+(8 人以上)

布局特点

  • 开放式:通透视野与空气流通
  • 半封闭:适度遮阳与隐私(藤架/凉棚)
  • 多功能:常与户外厨房结合

关键设施

  • 餐桌椅:耐候 + 舒适的户外家具
  • 遮阳设施:阳伞、凉棚、葡萄藤架
  • 照明设备:暖色低位灯,营造晚间氛围

辅助空间

  • 烹饪区:户外厨房或与室内厨房无缝衔接
  • 储物:餐具、桌布的就近收纳
  • 清洁:洗手台或户外水槽
— 03

🪑家具配置 / Furniture

主要家具

  • 餐桌:实木、铁艺、石面——耐候是首要标准
  • 餐椅:舒适且耐风雨,带可拆洗坐垫为佳
  • 边桌或吧台:摆放饮料与餐前小食

耐候性要求

  • 防水:抵抗雨水与湿气
  • 防紫外线:防止材质褪色变形
  • 耐腐蚀:海边项目需考虑盐雾防护

舒适度考虑

  • 桌椅高度与角度的人体工程学
  • 表面材质的触感(避免暴晒后烫手)
  • 家具稳定性,防风固定设计
— 04

🎨风格建议 / Style Match

户外用餐是地中海体系的灵魂场景

最匹配的风格

  • 地中海庭院:户外用餐就是为它而生——长桌、葡萄藤架、橄榄树
  • 托斯卡纳庭院:葡萄藤架下的长午餐是经典画面
  • 普罗旺斯花园:薰衣草田边的家庭晚餐
  • 英式乡村花园:玫瑰花境旁的铸铁桌下午茶

较克制的风格

  • 新中式 / 侘寂:更适合"茶席"而非"聚餐"——尺度与气质都更小
  • 现代极简 / 低调景观:可做但需要精心设计,避免成为"样板间式餐桌"

氛围营造要点

  • 暖光为主:橙黄色 LED 灯串、蜡烛、火盆
  • 植物围合:用植物制造"室外房间"的感觉
  • 声音背景:水景、风铃、轻音乐
— 05

🌤️季节适应 / Seasonal

全年使用

  • 春:樱花/玫瑰盛开,户外晚餐复苏
  • 夏:凉风、葡萄藤遮阴,核心使用季
  • 秋:落叶诗意,晚餐+毯子组合
  • 冬:暖光+火盆+厚毯,仅适合温暖地区

天气保护

  • 雨水:可移动雨棚或室内备用方案
  • 风力:防风固定设计,海边项目尤重要
  • 极端天气:必须有室内备用计划
— 06

🛠️技术配置 / Technical

照明设计

  • LED 灯串与地灯的柔和氛围照明
  • 烛台、灯笼、火盆的"暖光仪式"
  • 调光控制——晚餐照明需要"暖且暗"

音响系统

  • 户外防水音箱(避免干扰邻里)
  • 蓝牙连接的便利性
  • 背景音乐的音量克制

遮阳设施

  • 固定凉棚:永久性遮阳,可承载藤本植物
  • 移动阳伞:灵活的午餐遮阳
  • 智能遮阳:可电动收放的阳光系统

智能控制

  • 感应/定时照明
  • 智能调温与加热设备
  • 安防与用餐区监控
— 07

🌿植栽配合 / Planting

氛围植物

  • 葡萄藤:户外用餐"顶棚"的最佳选择(地中海/托斯卡纳)
  • 紫藤、铁线莲:浪漫遮阴的藤本
  • 橄榄树:单株作背景或景观焦点

香气与食用

  • 食用香草:迷迭香、薄荷、罗勒——"边吃边摘"的乐趣
  • 芳香花卉:薰衣草、茉莉、夜来香
  • 柑橘类:柠檬、柚子——既好看又好用

隐私屏障

  • 绿篱:黄杨、女贞——稳定的边界
  • 高大乔木:形成自然遮挡
  • 攀爬植物:藤架上的垂直绿化
