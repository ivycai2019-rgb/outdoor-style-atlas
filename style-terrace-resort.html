风格简介 / Introduction

20 世纪后半叶国际度假酒店业从地中海各地传统中"提炼"出的通用模板:剥离西班牙、希腊、摩洛哥的具体地域符号,保留它们共同的"度假感"——无边泳池 + 棕榈剪影 + 户外沙发 + 黄昏酒会。它不是某一地的传统,而是"度假本身"的视觉版本。

核心气质
放松、奢华感、商业化。最适合短期居住与社交,设计师在做酒店、民宿、样板房项目时的"安全选项"。
起源 / 背景
起源于 1960–80 年代国际度假酒店业(Amanresorts、Aman、Four Seasons 等)对全球各地度假语言的整合,逐渐固化为一种"国际度假视觉标准"。
室内衔接
与现代度假、新东方酒店、自然现代、Resort Style 室内完美衔接;与古典欧式、新中式、Loft 室内不冲突但气质会被拉散——它是"商业化度假"的视觉,日常长期居住容易显空。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
无边泳池(infinity pool)——把水面与远处海平面/山线"拼"成一条线,是露台度假最强的视觉信号。
02
棕榈或大叶植物剪影——单株椰子树、棕榈或鹤望兰常作为画面前景剪影,黄昏时分尤其醒目。
03
户外沙发 + 大尺度坐具——白色或米色亚麻布艺、藤编低矮沙发,围绕火盆或低桌摆放——它的灵魂是"久坐",而不是"用餐"。
04
木质平台或大块石板地面——铺装统一、平整、低反光,木色或浅灰石材——剥离了西班牙赤陶或希腊白卵石的"地域感"。
05
黄昏暖光照明——低位射灯打亮泳池水底与植物,黄铜户外灯具,营造"日落鸡尾酒会"的标准画面——这是它与希腊蓝白(只用自然光)最大的氛围分界。
— 05

核心特征 / Core Features

空间结构
大尺度露台 + 无边泳池 + 户外起居区 + 户外用餐区 + 遮阳廊架。常以"泳池作为视觉中心"组织所有功能,空间开阔、视野远眺、几乎无围合。
动线关系
从室内直接走到泳池边——动线追求"无缝过渡",取消门槛、台阶。视线追求远景,常以泳池水面、海平面或山线作为视觉灭点。
植物语言
植物气质以姿态强烈的乔木为主角(棕榈、橄榄、鹤望兰、大叶榕),辅以耐旱地被。植物用量不大但每一株都是"画面焦点",强调剪影而非花量。
代表植物椰子树 · 棕榈 · 橄榄 · 鹤望兰 · 龙血树 · 多肉地被
水景关系
无边泳池是绝对核心。除此之外可能有镜面水景、户外淋浴、低位水墙。所有水景都强调"视觉延伸"——把眼睛带向远方。
光影氛围
白天靠强光与水面反射,傍晚靠精心设计的人造照明——低位射灯、泳池水底灯、火盆。"黄昏黄金时刻"是这个风格的标志性氛围,几乎所有营销摄影都在这一时段拍摄。
色彩系统
米白 / 浅灰 / 木色 / 棕榈深绿 / 海蓝。整体低饱和、带着"奢侈品广告"的克制感——刻意避免希腊蓝白的高对比与西班牙的高饱和,追求"国际通用度假调"。
材料系统
柚木或防腐木平台、浅灰石材、白色灰泥墙、藤编家具、黄铜户外灯具、亚麻布艺。材料追求"高级质感"与"国际酒店标准",不强调地域手作感。
休闲与活动
主要活动泳池游泳 · 户外鸡尾酒会 · 日光浴 · 朋友小聚 · 户外晚餐
推荐场景日落鸡尾酒 · 周末家庭聚会 · 节庆户外派对 · 度假短居
生活方式度假与短期居住为主 · 重视社交与"被拍照" · 节奏放松、追求仪式感

相关风格 / Related Styles

用于横向判断与边界划分
地中海庭院 Mediterranean Courtyard
相似:都用白墙 + 户外生活 + 耐旱植物。
差异:地中海庭院有地域文化根(西班牙、意大利、法国南部的具体传统),装饰、餐桌、铁艺都来自真实生活;露台度假是商业化提炼,剥离了地域细节,只保留"度假视觉" ——前者有"灵魂",后者有"标准"。
希腊蓝白庭院 Greek Island Garden
相似:都有无边泳池、海景、度假感。
差异:希腊蓝白有极端的视觉个性(纯白 + 爱琴蓝 + 九重葛粉),气质强烈;露台度假是"通用版本"——剥离了希腊的地域符号,色调更中性、更"国际酒店化"。前者像作品,后者像产品。
现代热带庭院 Modern Tropical Garden
相似:都重视无边泳池、棕榈剪影、户外起居。
差异:现代热带在湿热气候下加入大叶植物、深绿浓荫、藤编;露台度假在干暖气候下保留棕榈但减少植物密度,色调更冷。两者是同一商业模板在不同气候下的双胞胎。
现代极简庭院 Modern Minimal Garden
相似:都追求克制、低饱和、清晰几何。
差异:露台度假强调"度假感"——棕榈剪影、户外沙发、火盆、暖光,营造放松仪式;现代极简强调"建筑感"——几何水池、单一植物、冷调材料,不追求度假氛围。

适配性 / Suitability

SUITABLE SPACE · 适合空间
大露台 屋顶 海景花园 无边泳池区 度假别墅 酒店项目
必须有足够空间放下无边泳池 + 户外沙发组合,最少 150 ㎡。开阔露台、屋顶、有远景的庭院都适合。它是地中海体系里唯一适合屋顶的子类。
SUITABLE CLIMATE · 适合气候
温暖亚热带 海边 城市高层 温暖大陆性
气候适应性最强的地中海子类——不严格要求干暖,温暖湿润、海边、城市高层都能做。这正是商业化模板的优势:气候要求降到最低,可在全球部署。
MAINTENANCE · 维护难度
中
泳池系统维护、户外家具防晒防潮、植物季节性修剪——维护强度像一家"小型酒店"。植物本身不难,真正的成本在泳池水质 + 户外家具更换。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料柚木平台 · 浅灰石材 · 白色灰泥 · 藤编家具 · 黄铜灯具
核心植物椰子树 · 棕榈 · 橄榄 · 鹤望兰 · 龙血树
UNFIT SCENARIOS · 不适配场景
小尺度内院 日常长期居住 儿童活动主导 无远景的城市花园 寒冷气候
小尺度内院容不下无边泳池,核心丢失;日常长期居住容易显空——它是为度假/酒店场景设计的,缺日常生活密度;儿童活动主导的家庭不适合(无边泳池有安全风险);没有远景的城市花园做无边泳池"无处可边",失去意义。
