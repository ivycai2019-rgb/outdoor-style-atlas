风格简介 / Introduction

西班牙南部安达卢西亚地区在摩尔人统治八个世纪后形成的庭院传统:把伊斯兰的内向天井 + 中心水景 + 几何瓷砖,与西班牙农庄生活融合,创造出一种"既私密又日常"的庭院——它的灵魂在围合,在仪式,在精心维护的手作细节。

核心气质
内向、有仪式感、密度适中。地中海体系里最"安静"的子类——它不是用来开派对的庭院,而是用来度过整个夏日下午的庭院。
起源 / 背景
由 8–15 世纪摩尔人在伊比利亚半岛留下的伊斯兰造园传统,经过五百年的西班牙农庄生活吸收转化而成,最完整的实物保存在安达卢西亚地区(科尔多瓦、塞维利亚、格拉纳达)。
室内衔接
与西班牙乡村、Mexican Hacienda、Bohemian、农庄手作风格室内完美衔接;与现代极简、新中式、北欧室内冲突——它的"暖"和"密度"会被冷调极简消解。

风格识别点 / How to Recognize

在图片或案例中快速判断
01
四面回廊围合的天井——建筑物围出一个内向庭院,廊柱遮阳遮雨,中央露天——这是西班牙庭院最强的空间识别。
02
中心水景——一池、一钵、一道矮喷泉位于天井正中,常配几何瓷砖——伊斯兰"四水分流"传统的遗存。
03
蓝白瓷砖(azulejos)——墙面、池边、踢脚线上的几何或植物纹瓷砖——蓝、白、黄、绿是经典色,这是西班牙庭院与其他地中海子类最明显的分界。
04
挂满白墙的陶罐——大量手绘陶罐挂在白墙上或排在地面,种着天竺葵、薰衣草、薄荷——这是科尔多瓦"庭院节"标志性画面。
05
柑橘树孤植或对植——橘子树、柠檬树常作为庭院唯一的乔木,与中心水景构成画面焦点——比橄榄更具仪式感。
— 05

核心特征 / Core Features

空间结构
建筑四面围合 + 露天中庭(patio interior) + 中心水景 + 周边回廊。常见两种尺度:民居小型 patio(20–60 ㎡)与豪宅多 patio 组合(如阿尔罕布拉宫的多重庭院)。空间向内,与街道完全隔绝。
动线关系
直接进入中庭,无曲折。所有动线从回廊出发,环绕中庭走向各个房间。视线不是流动的,而是稳定停留在中庭水景上——它要的不是"游",而是"坐"。
植物语言
植物气质柑橘类乔木 + 大量盆栽花卉 + 攀爬植物的组合。植物用量大但被严格"装盆",几乎没有自由生长的花境——是"被驯化的繁茂"。
代表植物橘子树 · 柠檬树 · 天竺葵 · 茉莉 · 九重葛 · 棕榈
水景关系
中心方池或圆池 + 小型石喷泉 + 瓷砖水盆。比摩尔式「更生活化」(无伊斯兰十字水道的宗教象征),水主要服务于天井降温与日常用水,声音是副作用。
光影氛围
回廊投下的深阴影 + 中庭天井的强烈天光,构成戏剧化对比。中午前后阳光只能从天井垂直射入,形成"光柱"效果。夜景以铁艺烛台、低位暖光为主。
色彩系统
白(灰泥墙)+ 赤陶(地面/屋瓦)+ 蓝白瓷砖(几何图案)+ 柑橘黄(果实)+ 天竺葵红(花卉)。比经典地中海更密集多彩,瓷砖把蓝色提升到主色而非点缀。
材料系统
白色灰泥墙 + 赤陶砖瓦 + 蓝白几何瓷砖(azulejos)+ 锻铁栏杆与门窗 + 手绘陶罐 + 粗糙石材铺地。蓝白瓷砖是它与意大利、希腊地中海庭院最大的材料分界。
休闲与活动
主要活动下午乘凉 · 家庭聚餐 · 阅读 · 小型聚会 · 园艺照料
推荐场景夏日午后的阴影里 · 黄昏家庭晚餐 · 周末邻里来访 · 圣诞前的庭院花会
生活方式家庭中心化 · 一年中大半时间在庭院度过 · 重视"花的养护"作为日常仪式

相关风格 / Related Styles

用于横向判断与边界划分
摩尔式庭院 Moorish Patio
相似:西班牙庭院本身就是摩尔式的"在地化"演化版本,共享内向天井 + 中心水景 + 几何瓷砖。
差异:摩尔式更纯粹(伊斯兰几何对称、抽象图案、无肖像);西班牙庭院在五百年里加入了大量天主教生活方式——大量盆栽花卉、家庭餐桌、宗教意象,变得更"日常"而非"宗教"。
地中海庭院 Mediterranean Courtyard
相似:同属地中海体系,共享白墙 + 赤陶 + 户外生活基因。
差异:西班牙庭院是内向围合的(四面建筑围出天井),仪式感更强;经典地中海是外向延展的(露台、海景、葡萄藤架),更开放、更松弛。一个"向内坐",一个"向外看"。
东方庭院 Eastern Courtyard
相似:都是内向围合 + 中心元素的天井系统——这是不同文明独立发展出的同构。
差异:东方庭院以山石植物为中心,色彩低饱和,讲精神性;西班牙庭院以水景与瓷砖为中心,色彩饱和明亮,讲家庭日常。一个"对话天地",一个"承载生活"。
墨西哥庄园庭院 Mexican Hacienda
相似:墨西哥庄园直接继承自西班牙殖民庭院,共享大量基因。
差异:墨西哥版本在中美洲气候下色彩饱和度更高(粉红、明黄、湖蓝)、热带植物更多;西班牙原版色彩更克制、植物更地中海化。一个是"被热带化的西班牙"。

适配性 / Suitability

SUITABLE SPACE · 适合空间
内院 下沉院 中庭 合院别墅 小尺度
最理想是有四面围合的天井(20–100 ㎡)。它是地中海体系里唯一适合小内院的子类——尺度越小,围合感越强,反而越对味。露台/屋顶/开放海景区都不适合。
SUITABLE CLIMATE · 适合气候
干暖 亚热带 温暖大陆性 南方
原产地是干暖气候,所以华南、海南、云南、广东沿海可适配。华东要做需考虑梅雨季瓷砖与铁艺的维护。北方冬季柑橘类无法越冬,需用本土耐寒替代品种。
MAINTENANCE · 维护难度
中
水景需定期清洁防青苔,大量盆栽需逐盆浇水(无法用滴灌系统),瓷砖会缝隙发霉。维护频次中等,但"亲手照料花盆"是这个风格生活方式的一部分——不愿意天天打理就不要做。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料白色灰泥墙 · 赤陶砖瓦 · 蓝白几何瓷砖 · 锻铁 · 手绘陶罐
核心植物橘子树 · 柠檬树 · 天竺葵 · 茉莉 · 九重葛
UNFIT SCENARIOS · 不适配场景
开放露台 / 屋顶 寒冷气候 现代极简室内 不愿打理盆栽 追求"度假感"
开放露台/屋顶因为没有四面围合,西班牙庭院的灵魂(内向天井)立刻消失;寒冷地区柑橘无法越冬,瓷砖也会冻裂;现代极简室内与西班牙庭院的色彩密度、装饰密度严重冲突;如果只想"度假"不想"打理"——大量盆栽会变成累赘,直接选希腊蓝白或经典地中海更合适。
