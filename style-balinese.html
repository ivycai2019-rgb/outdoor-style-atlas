风格简介 / Introduction

巴厘风庭院源自印尼巴厘岛印度教文化下的家庭与寺庙庭院传统——每座巴厘家庭都有一座"家庙",庭院围绕家庙组织;同时巴厘的庭院承载着"每日仪式"(供奉、祈祷、家庭聚集)。20 世纪后期被国际度假酒店业(Aman、Como)放大,变成全球最具识别度的"东南亚度假视觉"。

核心气质
湿润、有精神性、慢节奏、有仪式感。它不是简单的"热带度假"——它承载着印度教世界观,把"每日仪式"嵌入空间。
起源 / 背景
由印尼巴厘岛印度教传统(自 14 世纪起)发展而来,1970 年代后被国际度假酒店业(尤其 Adrian Zecha 的 Amanresorts)系统化为"巴厘风度假视觉",80 年代后传遍全球度假市场。
室内衔接
与东南亚度假、Bohemian、新东方酒店、藤编自然室内完美衔接;与现代极简、新中式、欧式古典室内冲突——它的"密度 + 精神性 + 暖"撑不住冷调极简。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
火山石或砂岩石雕——巴厘特有的火山石与砂岩雕成的印度教神像、守门石狮、古拙石雕——是巴厘风庭院最强的视觉识别。
02
茅草顶亭子(Bale)——四柱茅草凉亭,坐落于水池边或植物丛中,作为"户外起居室"——是巴厘庭院的标志性建筑元素。
03
跌水石景与莲花池——跌水从石雕中流出、流入莲花池——印度教"圣水仪式"的庭院化版本,既是装饰也是精神性元素。
04
"Canang sari" 供品——小型棕榈叶编织盘上的鲜花供品,放置在石雕前、入口处——这是巴厘庭院"活的"的标志,每日由家庭成员更换。
05
椰子树与鸡蛋花——单株或几株椰子树高耸,鸡蛋花(frangipani)散落在地面——构成巴厘庭院"清晨气味"的核心。
— 05

核心特征 / Core Features

空间结构
传统巴厘家庭庭院按"三段"组织——前院(社交)+ 中院(家庙)+ 后院(厨房 + 家畜)。当代度假版本简化为:泳池 + 茅草亭 + 植物丛 + 户外用餐区。庭院与建筑深度融合,常见"建筑物 = 多个分散凉亭"。
动线 / 视线
蜿蜒石板路 + 隐藏式过道 + 跌水边的暂停点。视线追求"层层渐入"——每走过一段都揭示新的画面,从"外院世俗"到"内院神圣"。
植物语言
植物气质"大叶 + 高饱和花 + 椰子树为骨架"。比热带雨林庭园更有花——鸡蛋花、九重葛、姜花、扶桑等高饱和热带花是标志,而非纯绿丛林。
代表植物椰子树 · 鸡蛋花 · 九重葛 · 姜花 · 扶桑 · 龟背竹 · 棕榈 · 兰花
水景关系
水景是"圣水"——常见跌水石景(从神像石雕流出)、莲花池、户外淋浴。在度假酒店版本中,无边泳池常作为视觉中心。水的功能是宗教 + 实用(降温/沐浴)+ 视觉三重叠加。
光影氛围
巴厘的"金色光线"——清晨的雾气、午后强光打在椰叶上、黄昏的火盆与烛光——构成独特的"巴厘氛围"。夜景大量使用火盆、藤编灯笼、地埋灯,营造仪式感。
色彩系统
深绿(植物主导)+ 火山石灰黑 + 茅草褐 + 鸡蛋花白 + 九重葛粉 + 一抹印度教橙红。比热带雨林庭园更"暖"——茅草、火山石、火盆都带着暖色调。
材料系统
火山石、砂岩、印尼柚木、椰壳、茅草、藤编、麻绳、印染棉布——所有材料都带着"手工与时间"的痕迹。新材料、工业材料几乎不入流——巴厘风需要"百年寺庙气质"。
休闲与活动
主要活动瑜伽 · 户外冥想 · 户外淋浴 · 茅亭午睡 · SPA · 度假晚餐
推荐场景晨光瑜伽 · 雨后湿气 · 黄昏火盆 · 月夜泳池 · 圣水仪式
生活方式"东南亚慢生活 + 精神性" · 适合短期度假 · 重视感官与仪式 · 节奏极慢

相关风格 / Related Styles

用于横向判断与边界划分
热带雨林庭园 Tropical Garden
相似:同源热带湿热,共享大叶植物 + 跌水基因。
差异:热带雨林庭园是"纯植物丛林"——拒绝文化符号;巴厘风是"印尼宗教 + 度假"——大量石雕、茅亭、印度教意象。一个有"纯自然感",一个有"东南亚味"。
现代热带庭院 Modern Tropical Garden
相似:都用热带植物,都强调度假感。
差异:现代热带剥离文化符号(只剩植物 + 几何泳池 + 清水混凝土);巴厘风保留印尼文化符号(石雕、茅亭、神龛、供品)。一个是"无文化的热带",一个是"巴厘的热带"。
露台度假花园 Terrace Resort Garden
相似:都源自国际度假酒店业(Aman 等)的视觉提炼。
差异:露台度假是地中海/全球通用版本(剥离所有地域文化);巴厘风保留印尼根。两者都是"商业化度假视觉"的代表,但巴厘风更"有故事"。
日式庭院 Japanese Garden
相似:都强调精神性 + 水景 + 植物层次。
差异:日式是禅宗(空灵、低饱和、克制);巴厘风是印度教(丰盛、高饱和、热烈)。两种宗教世界观决定了两种完全不同的庭院美学——日式追求"少",巴厘追求"多"。
— 07

适配性 / Suitability

SUITABLE SPACE · 适合空间
中大庭院 度假别墅 海滨庭院 泳池区 商业度假酒店
最理想是有泳池或大型水景的度假别墅,300 ㎡+。需要空间撑起"茅亭 + 泳池 + 植物丛 + 户外用餐"的多个功能区。小尺度做不出巴厘风的多层次。
SUITABLE CLIMATE · 适合气候
热带 亚热带 湿热 海边
必须湿热全年无冬——这是巴厘原产气候。中国仅海南、华南沿海、台湾可适配。华东、华中冬季椰子树、鸡蛋花无法越冬;北方完全不能做。
MAINTENANCE · 维护难度
中
植物维护中等——湿热气候植物长得快但虫害多。真正的成本在茅草顶定期更换(2–3 年一次)、石雕清洁、泳池水循环。比热带雨林庭园略低,因为没有那么密的植物层次。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料火山石 · 砂岩石雕 · 印尼柚木 · 椰壳 · 茅草 · 藤编
核心植物椰子树 · 鸡蛋花 · 九重葛 · 姜花 · 扶桑 · 龟背竹
UNFIT SCENARIOS · 不适配场景
寒冷气候 日常长期居住 现代极简室内 小尺度 无宗教/仪式接受度
寒冷气候椰子树、鸡蛋花完全无法越冬;日常长期居住会嫌"过度度假感"——巴厘风本质是短期度假风格;现代极简室内会被巴厘风的密度与文化符号"覆盖";对印度教石雕、神龛、供品没有接受度的家庭做出来会显得突兀。"是否真喜欢东南亚文化"是它的隐性门槛。

巴厘岛 乌布 · 传统家庭庭院 (Bali Aga)
几个世纪累积 · 巴厘印度教传统
巴厘风庭院的原型——巴厘传统民居庭院仍然完整保留了印度教家庙、Bale 凉亭、跌水水景的组合,是研究"真正的巴厘庭院"的最直接来源。
标杆案例
A
Amandari · 巴厘乌布
Adrian Zecha / Aman · 1989
现代巴厘风庭院的"全球化样板"。Amanresorts 创始人 Adrian Zecha 把传统巴厘庭院文化与现代度假酒店融合,定义了 1990 年代后全球度假业的"巴厘视觉"。
标杆案例
A
乌布 · Bambu Indah Hotel
John Hardy · 2005
巴厘风的"极致自然版本"——用本土竹结构、传统建筑、雨林环境构造"巴厘原生体验"。是当代巴厘风庭院"反商业化"的代表。
标杆案例
B
海南 · 三亚 鸟巢度假村等巴厘风别墅
中国本土度假地产
中国本土对巴厘风的批量化应用。质量参差——可作为"中国版巴厘风"的对照样本,理解本土化的挑战。
落地案例
B
云南 西双版纳 · 傣族民居庭院
傣族本土文化
中国境内最接近巴厘庭院文化的本土版本——傣族干栏式建筑、佛教寺庙文化、热带植物组合方式与巴厘高度相似。是研究"东南亚 - 西南"庭院文化连续性的最佳源头。

备注说明
中国市场上"巴厘风"常被简化为"茅草顶 + 石雕摆件 + 几棵棕榈"——这是失败的本土化。真正的巴厘风庭院核心是"印度教家庙骨架 + 茅亭(Bale)+ 跌水圣水 + 大叶热带植物"四件套,缺一不立。判断标准:看是否真有"家庙"或"印度教石雕作为视觉中心"(而非装饰摆件)。
