风格简介 / Introduction

农庄庭园是欧美乡村农庄传统的庭院形态——菜地 + 果园 + 鸡舍 + 户外用餐区的实用组合,把自给自足的农庄生活完整放进庭院。1990 年代后受 Permaculture 永续农业与「从农场到餐桌」运动推动,在欧美中产花园中复兴。

核心气质
质朴、丰盛、生活感强、有归属感。比现代农庄更不修饰(杂物、农具直接外露),比英式乡村更生产化(以食物花园为核心)。
起源 / 背景
起源于 18–19 世纪欧美乡村家庭花园传统(美国 Homestead 文化、欧洲 farmstead),1990 年代后伴随 Permaculture(Bill Mollison 1978 创立)与「从农场到餐桌」运动重新被设计师关注。代表案例:Monticello(Jefferson 自宅)、River Cottage(英国 Devon)。
室内衔接
与农庄风、Modern Farmhouse、北欧、Provincial 室内完美衔接;与现代极简、新中式、地中海冲突。

风格识别点 / How to Recognize

在图片或案例中快速判断
01
菜地占主体——前院或后院最大区域是真正的菜畦,种番茄、辣椒、生菜、南瓜等当季蔬菜——不是装饰,是真在吃。
02
果树园分散于庭园中——苹果、梨、樱桃等果树作骨架植物,既遮阴又产出。
03
鸡舍 + 工具棚——农庄庭园必有的实用建筑,虽不显眼但是「真实农庄」的标志。
04
晾衣架与雨水桶——日常生活物件直接出现在庭园中,反映真实使用——不是「样板间」。
05
木板栅栏与铁丝网——围栏用最普通的农庄材料,功能优先于美观。
— 05

核心特征 / Core Features

空间结构
菜地 + 果树园 + 鸡舍 + 工具棚 + 简单花境 + 户外用餐区——多个功能区并存,以"能不能用"组织,而非"能不能看"。围栏常用木板或铁丝网。
动线 / 视线
直线为主——便于推车、浇水、采摘。菜畦行距是动线骨架。视线追求"看到自己种的食物"的满足感。
植物语言
植物气质食用为主 + 观赏次之。菜畦(番茄、辣椒、生菜、南瓜)+ 香草(罗勒、迷迭香、薄荷)+ 果树(苹果、梨、柑橘)+ 自播花卉(向日葵、波斯菊)。植物的"实用性"优先。
代表植物番茄 · 香草 · 苹果/梨 · 葡萄 · 向日葵 · 大波斯菊 · 万寿菊(防虫)
水景关系
没有装饰水景。水的功能完全是实用的——雨水桶收集灌溉用水、水井、小型生态池(养鱼养鸭子)。
光影氛围
日常光线——农庄庭园几乎不强调夜景,日出后即开始劳作。夏夜户外用餐使用简单串灯或马灯,氛围质朴。
色彩系统
绿(蔬果)+ 木栏褐 + 红砖橙 + 季节花色(向日葵黄/南瓜橙)。色彩跟着季节物候自然变化,没有"设计色卡"概念。
材料系统
木板栏、铁丝网、再生砖、稻草秆、麻绳、农具铸铁。所有材料都"能买到的常见物",不追求精致——农庄庭园追求"能修就修,坏了就换"。
休闲与活动
主要活动种菜 · 采摘 · 户外用餐 · 烘焙 · 晾晒 · 照料动物
推荐场景春种 · 夏摘 · 秋收 · 冬储 · 家庭日常劳作 · 周末家庭工作
生活方式"从农场到餐桌"理想者 · 接受劳动量 · 重视食物溯源与家庭实用
— 06

适配性 / Suitability

SUITABLE SPACE · 适合空间
大庭院 乡村农舍 郊区后院 退休庄园
必须有足够空间——菜地最少 50 ㎡ 才有意义,加上果树与鸡舍需 200 ㎡+。小庭院只能做"缩小版"(几个高架菜畦),气质会大幅减弱。
SUITABLE CLIMATE · 适合气候
温带 亚热带 四季分明 湿润
气候适应性广——农庄庭园根据当地物候选植物即可。中国华东、华北、华南都能做,只需更换菜与水果品种。
MAINTENANCE · 维护难度
极高
维护强度最高——种菜需要每周劳作,果树需要修剪与防虫,鸡舍需要清洁。"农庄庭园 = 第二份兼职"。但这种劳作本身是它的乐趣,不是负担。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料木板栏 · 铁丝网 · 再生砖 · 稻草 · 麻绳 · 农具铸铁
核心植物番茄 · 香草 · 果树 · 葡萄 · 自播花卉
UNFIT SCENARIOS · 不适配场景
小尺度 现代极简室内 没有种菜意愿 城市高层 追求"打卡感"
小尺度撑不起多功能区;现代极简或欧式古典室内严重冲突;"没有真心想种菜养鸡的家庭千万不要做"——做出来 1 年后会因为劳作量超出预期而废弃;城市高层无土壤无法落地;追求拍照打卡的家庭会失望——农庄庭园的"美"来自真实劳作。

代表案例与来源 / Reference Projects & Sources

A
River Cottage · 英国
Hugh Fearnley-Whittingstall · 1990s 至今
当代农庄庭园的代表性实景。英国厨师把自家农庄改造为"从农场到餐桌"的实验场,通过电视节目影响整个西方农庄庭园文化。

A
Monticello 庭园 · Thomas Jefferson 自宅
Thomas Jefferson · 1770–1826
美国农庄庭园的历史样板。杰斐逊在自家庄园种植 330 多种蔬菜与 170 多种果树,详细记录每一种——是"实验性农庄庭院"的开山之作。

备注说明

相关风格 / Related Styles

食用花园Edible Garden
相似:同体系兄弟,都强调"能吃"。
差异:食用花园专注"美学化的菜园"(高架菜畦、对称布局、装饰边界);农庄庭园是"完整农庄"(菜地+果园+鸡舍+晾衣)。一个是"美的菜园",一个是"真实的农庄"。
英式乡村花园English Cottage Garden
相似:都有家庭日常感与"松弛丰盛"。
差异:英式乡村"花园美学优先"(玫瑰花境为主,菜地是配角);农庄庭园"实用优先"(菜地为主,花卉是配角)。一个为"观赏",一个为"使用"。
普罗旺斯花园Provence Garden
相似:都属于乡村美学,共享"慢生活"价值。
差异:普罗旺斯"度假感乡村"(度假房 + 葡萄藤午餐);农庄庭园"日常乡村"(常住 + 日常劳作)。一个像"暑假",一个像"退休生活"。
野趣花园Wild Garden
相似:同体系兄弟,都"反精致"。
差异:野趣花园是"放任的野"(本土植物自由生长,无功能区);农庄庭园是"有功能的野"(每片地都有用途)。野趣无产出,农庄有产出。
