风格简介 / Introduction

休闲泳池花园起源于 20 世纪美国加州/佛罗里达/澳洲悉尼的「家庭后院泳池」文化——把游泳从体育馆移到自家庭院。1980 后被全球度假别墅市场广泛吸收。

核心气质
实用、休闲、有「夏日感」。比海岛度假「更日常」(不必有海景),比现代热带「更宽松」(不必有建筑师骨架)。
起源 / 背景
起源于 20 世纪美国加州/佛罗里达/澳洲悉尼的家庭后院泳池文化。1980 后被全球度假别墅市场广泛吸收。
室内衔接
与现代度假、加州现代、迈阿密风格、地中海室内完美衔接;与新中式、欧式古典、Loft 严重冲突。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
泳池占庭院主体——泳池占地表 40–60%,是空间的绝对中心,所有家具围绕它布置。
02
泳池边大尺度沙发——白色或米色亚麻布艺低矮沙发组合,常配大型遮阳伞或藤编凉亭。
03
木质露台(deck)环绕泳池——压力处理木做的 deck 直接与泳池边平接,人可赤脚走动。
04
装饰性棕榈或大叶植物——棕榈、鹤望兰、龙血树作泳池绿幕,植物量克制,不喧宾夺主。
05
水底灯 + 水边火盆——夜景必备组合,泳池水底蓝光 + 火盆暖光 = 「度假酒店」氛围。
— 05

核心特征 / Core Features

空间结构
泳池占庭院 40–60% + 木质露台 + 户外沙发 + 棕榈或大叶植物作背景 + BBQ/酒吧区。
动线 / 视线
从室内 → 露台 → 泳池边沙发 → 下水。简单直接,无曲折。
植物语言
植物气质「装饰性热带植物」——棕榈/鹤望兰/龙血树作为「泳池绿幕」。植物量克制,不与泳池争主角。
代表植物椰子树 · 棕榈 · 鹤望兰 · 九重葛 · 龙血树 · 朱蕉
水景关系
水景就是泳池本身。可配按摩池、滑梯、瀑布。
光影氛围
阳光下泳池水面的「波光」,夜间水底灯把整个庭院染蓝。
色彩系统
泳池蓝 + 木褐(露台)+ 棕榈深绿 + 白(户外家具)。5 色泳池调色板。
材料系统
压力处理木 deck、灰色石材、不锈钢、白色户外家具、藤编。
休闲与活动
游泳 · 日光浴 · BBQ · 朋友家宴 · 泳池派对。生活方式:有家庭/有朋友圈/夏季使用密集。
— 06

适配性 / Suitability

SUITABLE SPACE · 适合空间
大后院海滨庭院度假别墅商业酒店
需要至少 200 ㎡ 才能撑起标准泳池。
SUITABLE CLIMATE · 适合气候
温暖大陆性亚热带热带海洋性
需要夏季温暖——中国华南、海南可全年使用;华东、华中夏季可用,北方与西北只适合夏季短暂使用。
MAINTENANCE · 维护难度
中高
维护负担在「泳池水循环系统」——周清洁、月加药、季节性翻修。是「泳池本身的维护」而非花园。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料压力处理木 · 灰色石材 · 不锈钢 · 白色户外家具
核心植物棕榈 · 鹤望兰 · 九重葛 · 龙血树
UNFIT SCENARIOS · 不适配场景
小庭院无泳池需求低预算儿童无监护
小庭院容不下大泳池;无游泳需求做出来浪费;低预算无法负担泳池;儿童游泳需要长期监护。

相关风格 / Related Styles

都把「夏日户外」做成核心。差异:美式后院「草坪+BBQ」;泳池花园「泳池+游泳」。
