分析模块 / Modules

风格倾向图

Style Tendency Map

把已标记的风格放到 古典 ↔ 现代 × 东方 ↔ 西方 的坐标系,可视化看出偏好聚集区。

色彩与材料偏好

Color & Material

从核心收藏中提取共同的色彩调性(暖/冷/低饱和)与材料倾向(木/石/金属/混凝土)。

维护承受度

Maintenance Capacity

已收藏风格的维护难度分布,提示是否在偏好与现实之间存在落差。

生活方式画像

Lifestyle Persona

结合室内 + 室外偏好,推断生活节奏(慢/快)、社交模式(独处/聚会)、文化亲和度(东方/西方)。

室内外一致性

Indoor-Outdoor Consistency

识别室内偏好与室外偏好之间的冲突(例如室内极简却收藏热带雨林庭院),帮助理解审美张力。

推荐与下一步

Recommendations

基于偏好画像,推荐尚未浏览但可能匹配的风格,并提示需要深入研究的维度。

分析框架 / Framework

  • 🎨 色彩取向(暖 / 冷 / 低饱和 / 高饱和)
  • 🏛 文化亲和度(东方 / 西方 / 混合)
  • 🌿 自然性偏好(野趣 / 几何 / 中间)
  • 📐 空间气质(开放 / 围合 / 留白)
  • 🛠 维护承受度(低 / 中 / 高)
  • 💰 投入预算区间偏好
  • 🌤 气候适配真实度(原生 vs 强行套用)
  • 🔗 室内室外一致性 / 冲突
