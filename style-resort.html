风格简介 / Introduction

海岛度假花园是 1960 年后商业化度假酒店体系发展出的标准化热带庭院——无边泳池 + 椰子树 + 沙地 + 茅草顶四件套,服务于「放松、忘记日常」的视觉指令。最早由巴厘、马尔代夫、加勒比的奢华酒店定型,后被全球热带度假区复制。

核心气质
放松、明亮、有强烈「不工作」暗示。比巴厘风更去文化化(剥离宗教符号),比热带雨林更整洁(无杂植丛)。
起源 / 背景
1960s–1980s 在巴厘、塞舌尔、加勒比的奢华酒店建造潮中定型。代表案例:Amanpuri(普吉)、One&Only Reethi Rah(马尔代夫)、Four Seasons Bora Bora。它把度假感做成了可被全球复制的视觉模板。
室内衔接
与 Resort Style、热带 Bohemian、Tropical Modern 室内完美衔接;与中式古典、新古典、英式乡村冲突。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
椰子树或棕榈剪影——成排的椰子树或棕榈,黄昏时分构成「热带蜜月」标志画面。
02
无边泳池连接海平面——泳池水面与远处海平面拼成一条线,是海岛度假最强的视觉信号。
03
茅草顶亭子(bale)——四柱茅草凉亭散布于庭园中,作为「户外起居室」。
04
沙地或木栈道铺装——白沙或柚木栈道连接各功能区,踩起来有「踩在海边」的感觉。
05
火山石或本土自然石——景观石使用本地火山岩或粗糙天然石,与海岛地貌融合。
— 05

核心特征 / Core Features

空间结构
无边泳池 + 椰子树阵列 + 沙地/木栈道 + 茅草顶亭子 + 海景挑台。常常"建筑物 = 多个分散凉亭",每个都面向海或泳池开放。空间感开阔、低矮、横向延伸。
动线 / 视线
蜿蜒木栈道与沙地小径交错,从一个凉亭到另一个凉亭。视线"必须有海或泳池"——所有动线最终通向水,这是海岛度假与其他热带风格最大的区别。
植物语言
植物气质"椰子树为骨架 + 大叶植物为肌肉 + 高饱和花卉为点缀"。比巴厘风"更克制"(植物量不大),比热带雨林"更稀疏"(强调"剪影"而非密度)。
代表植物椰子树 · 棕榈 · 鹤望兰 · 鸡蛋花 · 九重葛 · 朱蕉 · 草坪
水景关系
无边泳池(infinity pool)是绝对核心。把泳池水面与远处海平面拼成一条线——是海岛度假花园最强的视觉信号。常配"水中坐椅"、"水边火盆"、"水疗 SPA 池"。
光影氛围
"黄昏黄金时刻"是所有海岛度假花园的招牌画面——椰子树剪影 + 泳池水面反光 + 海平面落日。夜景以"火盆 + 低位射灯 + 泳池水底光"为主,营造蜜月酒会氛围。
色彩系统
沙白 + 椰青 + 茅草褐 + 海蓝 + 一抹九重葛粉/鸡蛋花白。"5 色海岛调色板"——比露台度假更"暖且自然"。
材料系统
椰壳、茅草、柚木栈道、藤编、麻绳、印染棉布、本地火山石、白沙——所有材料都"本土 + 自然 + 手作感"。新材料尽量不入眼。
休闲与活动
主要活动泳池游泳 · 海岛 SPA · 户外鸡尾酒 · 蜜月晚餐 · 黄昏散步 · 浮潜
推荐场景蜜月日落 · 度假早餐 · 夜间火盆 · 海风晚餐 · 椰林午睡
生活方式蜜月夫妇 · 高端度假短居 · 重视"蜜月感" + "被服务" · 节奏极慢

适配性 / Suitability

SUITABLE SPACE · 适合空间
海滨别墅 度假酒店 海景花园 岛屿庄园
必须在海岛或海滨——是 10 风格里"地理位置要求最严苛"的。城市内陆几乎无法做出真正的海岛度假感。需要至少 500 ㎡ 撑起椰林 + 泳池 + 凉亭。
SUITABLE CLIMATE · 适合气候
热带 亚热带 海洋性 全年温暖
必须"全年无冬" + "有海"。中国仅海南、台湾南部、华南沿海能真正适配。其他地区做出来气质会"失真"——椰子树冬季会枯,海风没了氛围就消失。
MAINTENANCE · 维护难度
中
植物维护中等——湿热气候植物长得快但易病害。主要负担在"茅草顶 2–3 年一换"、"泳池盐雾防护"、"木栈道防腐"、"沙地清洁"。比巴厘风简单些(没那么多石雕)。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料椰壳 · 茅草 · 柚木 · 藤编 · 火山石 · 白沙
核心植物椰子树 · 棕榈 · 鸡蛋花 · 九重葛 · 鹤望兰
UNFIT SCENARIOS · 不适配场景
内陆城市 寒冷气候 长期日常居住 无海景 追求"日常感"
内陆城市没有海风;寒冷气候椰子树无法越冬;"日常长期居住的家庭会嫌'过度度假感'"——这是它本质上的局限,只适合短期度假/酒店项目;没海景就失去灵魂;追求"日常感"的家庭做出来会觉得空、不实用。

代表案例与来源 / Reference Projects & Sources

Soneva Fushi · 马尔代夫

相关风格 / Related Styles

巴厘风庭院Balinese Garden
相似:同源东南亚热带,共享椰子树 + 鸡蛋花 + 茅亭基因。
差异:海岛度假"剥离巴厘文化符号"(无家庙/无供品/无石雕);巴厘风"保留印尼文化"。一个为"全球度假视觉",一个为"巴厘文化体验"。
露台度假花园Terrace Resort Garden
相似:都源自国际度假酒店业的视觉提炼。
差异:海岛度假"必须有海岛"(地理特定);露台度假"全球通用"(地中海/加勒比/任何海滨/内陆都行)。前者更"地理专属",后者更"通用模板"。
现代热带庭院Modern Tropical Garden
相似:同属热带,共享大叶植物。
差异:海岛度假"自然手作感"(茅草 + 沙地 + 椰壳);现代热带"建筑师极简感"(清水混凝土 + 几何泳池)。前者"暖且松散",后者"冷且几何"。
希腊蓝白庭院Greek Island Garden
相似:都是海岛度假视觉。
差异:希腊蓝白"地中海干暖 + 减法极简"(纯白 + 蓝 + 极少植物);海岛度假"热带湿热 + 加法丰盛"(椰林 + 鸡蛋花 + 高饱和)。"两种海岛度假的反面"——同一概念在两种气候下的不同表达。
