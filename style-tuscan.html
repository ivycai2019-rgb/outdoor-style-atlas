风格简介 / Introduction

意大利中部托斯卡纳地区的山丘庄园花园——它继承了文艺复兴庄园的轴线、绿篱、雕塑、台地布局,又被几个世纪的农庄生活"磨"成了带着橄榄园与葡萄园的乡村版本。它是"贵族花园 × 农庄生活"的混合产物——古典骨架仍在,但已被时间柔化成日常。

核心气质
慢、暖、有古典感的乡村。比普罗旺斯更有"贵族骨架",比英式乡村更结构化,比意大利文艺复兴花园更松弛——介于多个风格之间的"意大利乡村中间态"。
起源 / 背景
由 15–16 世纪意大利文艺复兴庄园(美第奇家族在托斯卡纳的别墅花园)发展而来,经过几个世纪的农庄化演变,成为今天托斯卡纳乡村花园的母本。20 世纪后期通过《托斯卡纳艳阳下》《风之谷》等书籍与电影被全球化。
室内衔接
与托斯卡纳乡村、意大利乡村、Vintage 欧式、农庄风、Bohemian 室内完美衔接;与现代极简、新中式、Loft 严重冲突——它的"暖与有古典感"撑不住冷调极简。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
柏树阵列(cypress avenue)——一条直线小径两侧排满高耸的意大利柏树——是托斯卡纳最强的视觉信号,也是与所有其他乡村花园最显著的区别。
02
橄榄园 + 葡萄园——花园常常与橄榄园、葡萄园直接相连,看不出"花园"与"农田"的明确边界——这是它"贵族 + 农庄"双重身份的实物体现。
03
修剪绿篱与几何花池——黄杨、月桂被修剪成几何形,围合出方形或矩形花池——这是文艺复兴庄园基因的遗存,把"古典"放进了乡村花园里。
04
赤陶罐与古典雕塑——大型赤陶罐(常种着柠檬树或天竺葵)、石质雕塑、石喷泉——比普罗旺斯更"古典",比英式乡村更"地中海"。
05
赤陶屋顶 + 浅黄色灰泥墙——远景里常出现托斯卡纳特有的农庄建筑:赤陶瓦屋顶、温暖的浅黄色灰泥墙——这构成"托斯卡纳画面"的天然背景。
— 05

核心特征 / Core Features

空间结构
前院(轴线 + 柏树大道 + 圆形喷泉)+ 主庭院(几何花池 + 修剪绿篱 + 雕塑)+ 农庄区(橄榄园 + 葡萄园 + 菜地)+ 露台(户外用餐 + 葡萄藤架)。常依山丘地形分台地布局——这是托斯卡纳"多层次"的核心。
动线 / 视线
中轴对称 + 自然蜿蜒并存。主轴线常以柏树大道引导,通向远处的喷泉或雕塑;偏区则以蜿蜒的橄榄园小径与葡萄藤架延伸。视线追求"远眺托斯卡纳丘陵"——景观与农庄风景融为一体。
植物语言
植物气质"古典骨架 + 乡村丰盛"。前院用修剪绿篱、柏树阵列、几何花池(古典骨架);偏区用橄榄园、葡萄藤、香草花园、果树(乡村丰盛)——两个植物逻辑并存。
代表植物意大利柏 · 橄榄 · 葡萄 · 柠檬树 · 月桂 · 黄杨 · 迷迭香 · 鼠尾草 · 玫瑰
水景关系
水景是托斯卡纳的"古典骨架"之一——圆形或方形石喷泉位于主轴端点,矮喷泉、石水盆点缀偏区。水的功能是古典仪式 + 降温 + 灌溉三重叠加——比普罗旺斯多一层"仪式感"。
光影氛围
托斯卡纳金色光线——这是全世界摄影师追逐的"黄昏黄金时刻"。柏树阵列在金色光线中的长影、橄榄银叶的反光、赤陶屋顶的暖色——构成最经典的托斯卡纳画面。
色彩系统
橄榄银绿 + 柏树深绿 + 浅黄灰泥墙 + 赤陶橙 + 葡萄藤紫 + 石灰白。比普罗旺斯更暖(暖黄色调主导),比英式乡村更克制(色相少)。"金黄暖调"是托斯卡纳的核心色彩标签。
材料系统
浅黄色灰泥墙(stucco)、赤陶砖瓦、未抛光石材(travertine)、铁艺、橄榄木家具、大型赤陶罐、葡萄藤架的橡木立柱。材料以"百年农庄"质感为主,但比普罗旺斯多了一层古典石材(travertine, marble)。
休闲与活动
主要活动葡萄藤下午餐 · 橄榄园散步 · 户外烹饪 · 葡萄酒品鉴 · 朋友家庭聚会
推荐场景夏日长午餐 · 葡萄收获季 · 橄榄丰收 · 黄昏酒会 · 雨后橄榄园散步
生活方式"意大利慢生活"的具象化 · 葡萄酒文化 + 橄榄油文化 · 家庭与朋友聚会密度高 · 重视食物与庭院的直接连接

相关风格 / Related Styles

用于横向判断与边界划分
普罗旺斯花园 Provence Garden
相似:同属南欧山地乡村花园,共享橄榄、葡萄、香草、石头矮墙基因。
差异:托斯卡纳保留"贵族骨架"(柏树阵列、修剪绿篱、几何花池、古典喷泉);普罗旺斯更纯农庄(松散、无修剪、薰衣草球阵)。一个是"贵族农庄",一个是"纯农庄"。
意大利文艺复兴花园 Italian Renaissance Garden
相似:托斯卡纳庭院直接继承文艺复兴基因(轴线、绿篱、雕塑、台地)。
差异:文艺复兴花园是纯粹的贵族花园(几何严格、雕塑密集、无农庄元素);托斯卡纳是"被农庄化"的版本——保留骨架但充满橄榄园、葡萄园、菜地。一个是"给贵族看的",一个是"给家庭用的"。
地中海庭院 Mediterranean Courtyard
相似:同源地中海气候,共享橄榄、葡萄、户外用餐基因。
差异:地中海庭院更"露台度假"化(海景、户外餐桌、白墙赤陶);托斯卡纳更"山丘农庄"化(柏树阵列、葡萄园、古典骨架)。一个面向海,一个面向山。
英式乡村花园 English Cottage Garden
相似:都是欧洲乡村花园,强调家庭日常感。
差异:英式乡村湿润、繁盛、玫瑰为王;托斯卡纳干暖、克制、橄榄+柏树为王。英式以花卉为视觉中心,托斯卡纳以树形与轴线为视觉中心。
— 07

适配性 / Suitability

SUITABLE SPACE · 适合空间
大庭院 乡村庄园 山丘庄园 坡地花园 度假别墅
需要足够大的尺度撑起柏树阵列与轴线——最少 500 ㎡,理想 2000 ㎡+。必须有起伏地形(山丘、坡地)才能真正"立得住"——平地小庭院做出来气质会失真。是 6 个乡村风格里对尺度要求最高的。
SUITABLE CLIMATE · 适合气候
地中海气候 干暖 温暖大陆性 阳光充足
原生气候是托斯卡纳干暖气候——夏季干热、冬季温和、阳光充足。中国仅云南南部、海南、华南部分山地能真正适配。华东、华中梅雨季橄榄易病害,北方冬季橄榄与意大利柏无法越冬——做出来气质会失真。
MAINTENANCE · 维护难度
中高
看似"乡村放任",实则维护强度较高——修剪绿篱与柏树需要专业园艺师、橄榄园与葡萄园的农艺维护、季节性病虫害管理、橄榄丰收期的采摘。需要把它当成"小型农庄"来经营,不是"家庭花园"。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料浅黄灰泥墙 · 赤陶 · 未抛光石材(travertine)· 铁艺 · 橄榄木 · 大赤陶罐
核心植物意大利柏 · 橄榄 · 葡萄 · 柠檬 · 月桂 · 黄杨 · 迷迭香
UNFIT SCENARIOS · 不适配场景
小尺度 平地 寒冷气候 无农庄意愿 现代极简室内
小尺度撑不起柏树阵列与轴线;平地无起伏做不出"托斯卡纳山丘"感;寒冷气候橄榄、意大利柏无法越冬;没有"经营小型农庄"意愿的家庭不要做——托斯卡纳本质是农庄花园,不是装饰花园;现代极简室内严重冲突。"有山有地有时间有钱"是托斯卡纳的四大入场券——缺一不可。

代表案例与来源 / Reference Projects & Sources

A 权威 · B 优秀参考 · C 灵感印象
A
Villa Gamberaia · 佛罗伦萨近郊
17 世纪 · 后续多次修缮
托斯卡纳庭院的圣经。把文艺复兴几何骨架(柏树水道、修剪绿篱)与农庄生活完美融合,影响了欧美整个 20 世纪的"意大利乡村花园"想象。
标杆案例
A
Villa La Foce · 锡耶纳南部
Cecil Pinsent · 1924–1939
现代托斯卡纳庭院的母本。英国设计师 Cecil Pinsent 把传统文艺复兴元素与现代庄园生活结合——其中著名的"柏树坡道"成为托斯卡纳最被拍摄的画面之一。
标杆案例
A
Villa Medici (Fiesole) · 佛罗伦萨郊外
15 世纪 · 美第奇家族
托斯卡纳贵族花园的最早样本。美第奇家族的山丘别墅,展示了"把山丘转化为花园"的早期智慧——是托斯卡纳"山地分层"传统的源头。
标杆案例
B
托斯卡纳各 Agriturismo(农庄住宿)
Chianti / Val d'Orcia / Val di Chiana 等地区
托斯卡纳乡村的高品质农庄度假酒店——是"当代托斯卡纳庭院"最真实的实景样本。这里的庭院仍然延续着百年前的语汇。
落地案例
B
国内"意式乡村"地产项目
多个房企 · 2010s
中国房地产市场曾大量复制托斯卡纳风格——但因气候(湿热)与尺度(小)限制,绝大多数都失真。可作为"失败案例博物馆"——研究为什么本土化总不到位。

备注说明
"托斯卡纳风"在中国房地产中被大量误用——常做成"浅黄外墙 + 几棵柏树"的装饰主义版本。真正的托斯卡纳庭院核心是"古典轴线骨架 + 农庄实景(橄榄园/葡萄园/菜地)+ 山丘地形 + 慢生活方式"四件套,缺一不立。判断标准:看是否有真正的橄榄园或葡萄园在花园旁,而非"装饰柏树"。
