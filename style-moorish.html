风格简介 / Introduction

伊斯兰世界对"花园"的原始想象——古兰经里描述的天堂有四条河流、永不凋谢的果园。摩尔式庭院把这套宗教意象翻译成空间:四等分天井、十字水道、对称种植、几何瓷砖,在干燥酷热的沙漠或半沙漠气候里造出一片"可被相信的天堂"。

核心气质
几何、对称、神圣感、降温效果。地中海体系里最有"宗教仪式感"的子类——它不是世俗生活的庭院,而是被信仰组织起来的空间。
起源 / 背景
起源于波斯(古兰经天堂园模型),经伊斯兰扩张传到北非与西班牙南部。8–15 世纪在伊比利亚半岛达到巅峰,最完整的实物是格拉纳达的阿尔罕布拉宫。
室内衔接
与摩洛哥、波斯、Andalusian、中东风格室内完美衔接;与现代极简、北欧、新中式室内冲突——它的几何密度与色彩饱和度太高。

风格识别点 / How to Recognize

在图片或案例中快速判断
01
十字水道(chahar bagh)——庭院被两条十字水道分成四等份,象征古兰经里的四条河——这是摩尔式最强、最不可替代的识别。
02
几何对称布局——所有植物、水景、铺装严格沿中轴对称,与西班牙庭院的"日常感"形成对比——摩尔式是仪式的,西班牙是生活的。
03
抽象几何瓷砖与雕花——伊斯兰禁止具象图像,所以装饰只用几何、星形、植物花纹的瓷砖与灰泥雕花(yeseria)——是与天主教影响下的西班牙庭院的关键分界。
04
下沉式种植池——植物种在低于人行铺装的下沉花池里,这样从廊下看出去,人眼高度看到的是花的顶部 + 远处建筑,而不是花根——一种独特的视觉控制。
05
柑橘树对植阵列——常以多排柑橘树或柏树构成对称阵列,而不是孤植——是"果园天堂"概念的视觉实现。
— 05

核心特征 / Core Features

空间结构
四面建筑围合 + 中央"四分园"(chahar bagh)+ 十字水道 + 廊柱阵列 + 中心水池或亭阁。空间严格几何化,中轴对称,常见多个庭院串联(如阿尔罕布拉宫的"狮子庭"+"桃金娘庭")。
动线关系
沿中轴或水道行走,几乎没有曲折。视线被精心控制——通过门洞、廊柱、水道形成"视线在轴线上消失"的效果。中心交点是空间的灵魂。
植物语言
植物气质以果树(尤其柑橘)、芳香植物、玫瑰为主,按对称几何排布,种在下沉花池里。强调"果园" + "芬芳" + "永恒常绿"——这是对古兰经天堂园描述的直译。
代表植物橘子树 · 柠檬树 · 柏树 · 玫瑰 · 桃金娘 · 茉莉
水景关系
水是绝对的主角,且必须是流动的。十字水道 + 中心圆池 + 矮喷泉构成"水的系统"。水的功能是宗教(象征天堂河流) + 实用(蒸发降温) + 美学(声音与倒影)三重叠加。
光影氛围
伊斯兰建筑的雕花拱、镂空窗格在白墙上投出复杂图案,水面反射光斑到墙顶。中午阳光直射时下沉花池有阴影,人在廊下,光在水上——是"被几何化的光"。
色彩系统
白(灰泥墙)+ 蓝(瓷砖)+ 绿(柑橘叶 + 柏树)+ 金黄(柑橘果实)+ 深红(瓷砖图案)。比西班牙庭院更抽象多彩——色彩主要来自瓷砖与雕花,而非花卉本身。
材料系统
白色灰泥墙 + 几何瓷砖(zellige)+ 雕花灰泥(yeseria)+ 蜜糖色石材 + 雪松木格栅(mashrabiya)+ 黄铜灯具。瓷砖与灰泥雕花是它与所有其他地中海子类最显著的材料分界。
休闲与活动
主要活动沉思 · 阅读古兰经 · 听水声 · 小型雅集 · 沿水道散步
推荐场景清晨的水道反光 · 黄昏的几何阴影 · 月光下的瓷砖墙 · 斋月的家庭聚会
生活方式宗教与日常深度融合 · 庭院承担"精神空间"功能 · 强调对称与秩序

相关风格 / Related Styles

用于横向判断与边界划分
西班牙庭院 Spanish Courtyard
相似:西班牙庭院的骨架直接来自摩尔式,共享内向天井 + 中心水景 + 几何瓷砖。
差异:摩尔式是纯粹的宗教空间(伊斯兰几何对称、十字水道、无具象图像);西班牙庭院在五百年里被天主教生活方式"软化"了——加入大量盆栽花卉、家庭餐桌,几何对称变得松弛。
波斯式庭院 Persian Garden
相似:摩尔式的"祖父辈"——古兰经天堂园的最原始版本就在波斯。共享四分园、十字水道、对称布局。
差异:波斯庭院尺度更宏大(常作为皇家园林,如伊斯法罕),用于狩猎、宴会、政治仪式;摩尔式 patio 是城市化的小尺度版本,被嵌入民居与宫殿的天井里。
法式规整花园 French Formal Garden
相似:都强调几何对称、中轴秩序、水景的仪式化。
差异:摩尔式是"内向"的几何(围合天井、抽象瓷砖、宗教意象);法式规整是"外向"的几何(开放草坪、雕塑喷泉、君主权力的展示)。一个面向真主,一个面向国王。
摩洛哥庭院 Moroccan Riad
相似:摩洛哥 Riad 是摩尔式在北非的当代延续版本。共享几何瓷砖、中心水景、内向天井。
差异:摩洛哥版本饱和度更高(橙、粉、宝石蓝)、装饰更繁复(更多手工铜灯、地毯、坐垫),更适合现代度假酒店;西班牙摩尔式更历史化、克制。

适配性 / Suitability

SUITABLE SPACE · 适合空间
内院 中庭 合院别墅 下沉院 大尺度天井
必须是有四面围合的天井,且尺度需要足够撑起十字水道 + 对称种植阵列——最少 60 ㎡,理想 100–300 ㎡。露台、屋顶、开放庭院都不适合。
SUITABLE CLIMATE · 适合气候
干旱 半干旱 温暖大陆性 南方亚热带
摩尔式的原生气候是干旱炎热,水景降温与四面围合避暑是它的功能性核心。中国语境下华南、西北部分地区可适配。湿润多雨地区强行做会失去"水的稀缺感",同时瓷砖与水道易长青苔。
MAINTENANCE · 维护难度
中高
水道系统需循环、过滤、防漏防青苔,维护频次高;手工瓷砖与雕花灰泥年代久会需要专业修复;对称种植阵列要求每一棵植物状态接近——一棵长不好整组就破坏。是地中海体系里维护难度最高的子类。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料几何瓷砖 zellige · 雕花灰泥 yeseria · 蜜糖色石材 · 雪松木格栅
核心植物橘子树 · 柠檬树 · 柏树 · 玫瑰 · 桃金娘
UNFIT SCENARIOS · 不适配场景
小尺度内院 露台 / 屋顶 无水循环条件 现代极简室内 不愿做手工瓷砖
尺度不够撑不起十字水道,几何骨架立不住;露台屋顶无围合天井,核心丢失;水道系统对建筑给排水有专门要求,无条件改造的项目做不出来;用工业瓷砖替代手工 zellige 是常见误区——视觉立刻廉价化,这点比尺度更致命。

代表案例与来源 / Reference Projects & Sources

A 权威 · B 优秀参考 · C 灵感印象
A
格拉纳达 · 阿尔罕布拉宫 (Alhambra)
13–14 世纪 · 纳斯里德王朝
摩尔式庭院的最高样本,联合国教科文组织世界遗产。狮子庭、桃金娘庭、玫瑰庭组合,是研究"伊斯兰几何 + 天堂园模型"的唯一完整实物。

格拉纳达 · 轩尼洛里菲花园 (Generalife)
13 世纪 · 纳斯里德避暑别宫
阿尔罕布拉宫的姐妹花园。展示了摩尔式在"农耕天堂园"语境下的另一种形态——果园、菜圃、十字水道与建筑融合。
标杆案例
A
科尔多瓦 · 大清真寺橘园 (Patio de los Naranjos)
8 世纪 · 倭马亚王朝
摩尔式"果园天堂园"最早的样本之一。整个庭院是橘子树阵列 + 灌溉沟渠,展现了"花园即果园即朝拜空间"的原始概念。

摩洛哥 马拉喀什 · Le Jardin Secret 庭院
19 世纪 · 现代修复
摩尔式在北非的现代修复样本。把传统天堂园模型严格还原,是当代设计师研究摩尔式的最易访问的高品质参考。
