风格简介 / Introduction

"虽由人作,宛自天开"——中式庭院涵盖北方四合院、江南文人园、岭南天井院、徽州天井院四大母体。共同基因是院落 + 廊 + 山水 + 植物 + 楹联,既是居所也是文人精神空间。

核心气质
含蓄、文气、富有诗意。可观可游可居,讲究"框景、对景、漏景、借景"等四境法门。
起源 / 背景
从秦汉皇家苑囿、唐宋文人别业,到明清苏州园林、北京四合院,跨越两千多年。明代计成《园冶》是造园理论高峰。
室内衔接
与中式古典、明式家具室内、复古宅院风格完美衔接;与现代极简、北欧、Loft 室内冲突——更适合新中式重写后再用。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
廊院组合——廊不是装饰物,而是组织空间的核心元素,把不同院落串联成可游走的整体——这是中式庭院最强的结构特征。
02
漏窗与花窗——墙上的几何或植物花窗,在墙面投出图案、把外景"漏"进来——传统中式特有的"框景"语言,新中式已不再用。
03
太湖石与置石——以"瘦、皱、漏、透"为美的造型石,常作为水边或庭院焦点,几乎只在江南文人园出现。
04
白墙黛瓦或朱漆红墙——江南是白墙黛瓦的冷调,北方是朱漆红墙的暖调——一眼可判断地域版本。
05
楹联匾额——亭、廊、门头上常挂楹联或题字匾额,把文学性直接嵌入空间——这是中式庭院与日式庭院最大的区别之一。
— 05

核心特征 / Core Features

空间结构
四大子类:北方四合院(中轴对称、正院 + 跨院)、江南文人园(自由曲折、池为中心)、岭南庭院(天井 + 通风 + 水景)、徽州天井院(高墙 + 小天井 + 四水归堂)。
动线关系
游园式弯曲路径 + 廊院串联 + 漏窗框景。强调"步移景异",反对一眼看穿。路径本身就是观赏内容。
植物语言
植物气质以"文人四君子"(梅兰竹菊)为骨,辅以姿态型乔木(松柏玉兰芭蕉)、季相花木(海棠桂花)、文房盆栽。强调诗意与四季感,而非花量与色彩。
代表植物松柏 · 芭蕉 · 玉兰 · 海棠 · 梅兰竹菊 · 紫藤
水景关系
水是中式庭院的灵魂之一。江南文人园以池为中心(拙政园、留园),北方常用浅水或井,岭南偏鱼池与天井雨水。常配亭、廊、桥,形成"水中映景"。
光影氛围
依赖白墙、漏窗与廊架投影。漏窗在白墙上的几何投影是经典语言,廊下的光斑变化、月夜下的院落剪影构成"诗意光影"。夜景以灯笼、廊灯为主,克制不喧。
色彩系统
青灰瓦 / 朱漆 / 红墙(北方) / 白墙黛瓦(南方) / 木栗色 / 深绿。北方偏暖色明艳,南方偏冷色含蓄。
材料系统
青砖、青石板、太湖石(江南) / 灵璧石、漏窗、雕花木构、彩绘梁柱、瓦顶、夯土墙、楹联匾额。木构 + 石 + 砖三件套是基本盘。
休闲与活动
主要活动文人雅集 · 抚琴 · 品茶 · 弈棋 · 看书 · 赏花
推荐场景春赏海棠 · 夏听蛙鸣 · 秋观桂月 · 冬赏腊梅
生活方式家族聚居 + 文人独处 + 偶尔雅集招待 · 节庆与四季紧密相关

相关风格 / Related Styles

用于横向判断与边界划分
新中式庭院Modern Chinese Garden
相似:同源东方造园基因,植物语汇高度重叠。
差异:中式有雕花、彩绘、博古架、繁复木构;新中式剥离了这些,只留几何与材料。若与现代室内搭配,几乎只能选新中式。中式是完整继承,新中式是选择性继承。
苏式园林Suzhou Garden
相似:苏式园林本身就是中式庭院的子类。
差异:苏式园林是中式庭院的江南文人版本,更小巧曲折、更书卷气。中式涵盖了北方四合院、徽州、岭南等其他地域版本。
日式庭院Japanese Garden
相似:同源东方造园,共享植物语汇(松、枫、竹、梅)。
差异:中式更文人化(楹联、文房意象、廊亭书院);日式更禅宗化(踏石、苔藓、池泉)。中式偏文人雅集,日式偏禅修茶道。
岭南庭院Lingnan Garden
相似:岭南庭院是中式庭院的华南子类。
差异:岭南庭院因气候(湿热)发展出天井 + 通风 + 水景系统,植物更丰盛色彩更艳;江南文人园与北方四合院更内敛克制。

适配性 / Suitability

SUITABLE SPACE · 适合空间
中庭院 大庭院 合院别墅 仿古宅院
200 ㎡ 起步,完整的中式庭院通常需要 500 ㎡ 以上。小尺度只能做"小景"(天井院、漏窗院、坪庭式)。不适合露台、屋顶、城市公寓阳台。
SUITABLE CLIMATE · 适合气候
温带 亚热带 季风 全国适配
是少数全国可适配的风格——北方做四合院、江南做文人园、华南做岭南天井、徽州做高墙天井,各有版本。但植物与材质需按地域调整。
MAINTENANCE · 维护难度
高
木构需防腐防潮、彩绘需补漆、太湖石与花木需修剪、池塘需循环水管理、楹联匾额需保养。是东方体系中维护最重的版本——传统中式庭院本就预设有"花匠+木工+漆工"团队长期照看。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料青砖 · 青石板 · 太湖石 · 雕花木构 · 漏窗 · 瓦顶
核心植物松柏 · 芭蕉 · 玉兰 · 海棠 · 梅兰竹菊 · 紫藤
UNFIT SCENARIOS · 不适配场景
现代极简室内 小尺度公寓 露台 / 屋顶 无木工漆工维护 气质单一化
与现代极简、Loft、北欧室内搭配会形成强烈断裂(应改用新中式);小公寓、露台、屋顶尺度撑不起完整的廊院与池水系统;雕花木构与彩绘需长期木工漆工维护,否则会迅速破败;同一空间内混用北方四合院 + 江南文人园 + 岭南元素是常见误区,必须先锁定地域版本。

代表案例与来源 / Reference Projects & Sources

A 权威 · B 优秀参考 · C 灵感印象
A
苏州 · 拙政园
明 · 王献臣 · 1509
江南文人园林的最高典范。以水为中心,园景分东中西三部分,典型"以小见大、以曲取胜"。被列入世界文化遗产。
标杆案例
A
苏州 · 留园
明清 · 多次修建
中国四大名园之一,以建筑与花木为主、水面为辅。空间组织极致紧凑,"廊"的运用堪称典范。
标杆案例
A
北京 · 恭王府花园(萃锦园)
清 · 18 世纪
北方私家园林的代表。中轴对称 + 北方建筑符号(红墙、彩绘、宝鼎),展示了与江南园林截然不同的北方版本。
标杆案例
A
广东 · 余荫山房
清 · 1871
岭南四大名园之一。以小巧、玲珑、精致著称,集江南园林之灵秀与岭南建筑之通透于一身。

观唐集团
