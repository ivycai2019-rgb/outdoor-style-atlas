风格简介 / Introduction

美式乡村花园起源于 18–19 世纪美国东海岸与中西部殖民地家庭花园——结合英式乡村花境传统 + 美国本土植物 + 殖民地实用主义。比英式乡村更克制、更结构化,在 20 世纪由插画家 Tasha Tudor 与 Martha Stewart Living 推向大众。

核心气质
温馨、家庭、四季有花。比英式乡村更克制(花量更少),比现代美式更传统(白栅栏 + 门廊摇椅是核心)。
起源 / 背景
源于 17–19 世纪殖民地新英格兰、中大西洋、南部种植园家庭花园传统,Williamsburg 在 1930 年代做了系统复原。当代复兴由 Tasha Tudor(Vermont 1970s–2008)、Martha Stewart Living 杂志(1990–2010s) 推动。
室内衔接
与殖民地风、Shaker、American Country、Coastal Cottage 室内完美衔接;与现代极简、Loft、亚洲极简冲突。

风格识别点 / How to Recognize

在图片或案例中快速判断
01
白色木栅栏——经典的白漆尖头木栅,是美式乡村最强的识别——「白栅栏 + 国旗」是美国梦的视觉。
02
前廊摇椅——独栋住宅前廊上的木摇椅或秋千,是「邻里社交」的物理表达。
03
本土花卉花境——向日葵、黑眼苏珊、紫锥菊、紫菀等美洲原生花卉,而非英式玫瑰。
04
入口拱门 + 砖路——白色木拱门或铁艺拱门 + 红砖小径——通向前廊的「迎宾走廊」。
05
美洲花楸/野苹果——结红果的本土小乔木,提供秋冬观赏与鸟食。
— 05

核心特征 / Core Features

空间结构
前庭花境 + 木栅栏 + 入口拱门 + 摇椅前廊 + 后院菜地。重视「「前庭社交」」——邻居路过会停下聊天。
动线 / 视线
从街道 → 木栅门 → 花境小径 → 前廊摇椅。这是「美国小镇生活」的物理表达。
植物语言
植物气质多年生草本 + 季节花卉 + 本土灌木 + 果树混合——比英式乡村「更本土」(用紫菀、向日葵、黑眼苏珊等美洲植物)。
代表植物向日葵 · 黑眼苏珊 · 紫菀 · 紫锥菊 · 雏菊 · 美洲花楸 · 苹果
水景关系
常见鸟浴盆(bird bath)— 不是装饰,是生态功能。
光影氛围
阴天的柔和漫射光 + 阳光下花境的明快感。
色彩系统
黄(向日葵)+ 紫(紫菀) + 粉(粉雏菊)+ 白栅栏 + 木褐(前廊)。「明快美式调色板」。
材料系统
白漆木栅栏、油漆木前廊、铸铁(摇椅/拱门)、本地砖、马口铁桶。
休闲与活动
邻里闲聊 · 摇椅闲坐 · 季节花卉欣赏 · 国旗装饰节庆。生活方式:美国小镇社区 · 重视邻里关系。
— 06

适配性 / Suitability

SUITABLE SPACE · 适合空间
独栋住宅前庭小镇社区郊区独栋乡村农舍
必须有前庭——这是美式乡村的灵魂。
SUITABLE CLIMATE · 适合气候
温带温带大陆性海洋性四季分明
原生气候是美国东海岸 + 中西部。中国华北、华中、东北可适配。
MAINTENANCE · 维护难度
中高
花境维护 + 木栅栏年度油漆 + 季节性花卉补种。比英式乡村略低,因为没有玫瑰拱门。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料白漆木栅栏 · 油漆木前廊 · 铸铁 · 本地砖
核心植物向日葵 · 黑眼苏珊 · 紫菀 · 紫锥菊 · 美洲花楸
UNFIT SCENARIOS · 不适配场景
现代极简城市公寓小尺度内院无邻里社交意愿
现代极简严重冲突;城市公寓无前庭;「无邻里社交」使前庭失去意义——美式乡村花园本质是「社区视觉」。

相关风格 / Related Styles

英式乡村花园English Cottage Garden
美式乡村是英式乡村的「美国版」。差异:美式更朴素(无玫瑰拱门)、更本土(美洲植物)、更社区(白栅栏+前廊)。
美式后院庭院American Backyard Garden
同体系兄弟。差异:美式乡村「前庭+花境」(向街道);美式后院「草坪+BBQ」(向内部)。
农庄庭园Farmhouse Garden
都强调实用。差异:农庄「完整生产」(菜+鸡);美式乡村「装饰为主+小菜地」。
法式乡村花园French Country Garden
都属乡村花园。差异:法式「几何骨架」;美式「自由花境」。
