风格简介 / Introduction

现代农庄庭院起源于 2000 年后美国 + 北欧的「Modern Farmhouse」潮流——Joanna Gaines 的《Fixer Upper》、北欧的「都市农耕」运动、Permaculture 的现代版本共同推动。它「剥离农庄的乡土感」,保留实用功能,加入现代极简骨架。

核心气质
实用、克制、现代感。比纯农庄「更精致」(无杂乱),比现代庭院「更生活化」(有真菜地/果园)。
起源 / 背景
起源于 2000 年后美国 Joanna Gaines「Modern Farmhouse」潮流 + 北欧都市农耕文化。Permaculture 现代版本(David Holmgren / Geoff Lawton 等)推动其生态化。
室内衔接
与 Modern Farmhouse 室内、Scandinavian、Japandi、北欧极简室内完美衔接;与传统欧式古典、新中式、巴厘风冲突。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
高架木菜畦阵列——方形木菜箱整齐排列,几何感强,把种菜从「劳作角落」变成「庭院主景」。
02
清水混凝土 deck 或铺装——主活动区用现代材料,与菜地的「实用感」形成对比。
03
耐候钢花池或边界——锈红色耐候钢用于花池、边界——是「现代农庄」最具识别度的现代材料。
04
白漆木栅栏——简洁的白漆栅栏围合花园,比纯农庄的木板栅更精致。
05
现代户外家具 + 餐桌——简约线条的木质或藤编家具,与农庄的家具完全不同——「种菜的人喝精品咖啡」感。
— 05

核心特征 / Core Features

空间结构
「菜地 + 果园 + 户外用餐 + 极简 deck」四区组合。比纯农庄「分区更清晰」,比现代庭院「更有生产」。
动线 / 视线
直线动线 + 几何菜畦阵列。从厨房直接走到菜地,从菜地直接走到 deck —— 「「厨房延伸」」是核心。
植物语言
植物气质「实用植物 + 现代极简家具」。蔬菜、香草、果树为主,但家具/铺装/边界都现代。
代表植物番茄 · 香草 · 苹果 · 梨 · 葡萄 · 草坪 · 多年生草本 · 观赏草
水景关系
水景常是「雨水收集池」或「极简浅水盆」——同时实用与现代。
光影氛围
北欧式柔光 + 现代灯具(线性 LED / 黄铜户外灯)。比纯农庄「更精致」。
色彩系统
深绿 + 木褐 + 白(墙)+ 灰(铺装)+ 蔬菜各色。「北欧 + 农庄合体」调色板。
材料系统
清水混凝土铺装、防腐木 deck、耐候钢花池、白漆木栅、藤编 + 现代户外家具。
休闲与活动
种菜 · 采摘 · 户外烹饪 · 家庭聚餐 · 永续农业实验。生活方式:「都市人逃离都市的生活」 · 重视食物溯源 + 极简美学。
— 06

适配性 / Suitability

SUITABLE SPACE · 适合空间
中庭院大后院乡村农舍现代化城市菜园 + 极简家具
100–500 ㎡ 最舒服。
SUITABLE CLIMATE · 适合气候
温带亚热带湿润通用气候
气候适应性广——选种季节蔬菜即可。中国大部分地区可适配。
MAINTENANCE · 维护难度
中高
维护包含「菜地每周打理 + deck 防腐 + 鸡舍清洁(若有)」。比纯农庄略低(因为没那么多杂物),比现代庭院高(因为有生产)。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料清水混凝土 · 防腐木 · 耐候钢 · 白漆木栅 · 藤编 + 现代家具
核心植物番茄 · 香草 · 苹果 · 梨 · 葡萄 · 多年生草本
UNFIT SCENARIOS · 不适配场景
纯装饰偏好传统中式室内小尺度阳台无种菜意愿
纯装饰偏好者会失望——必须有真菜地;传统中式室内严重冲突;小阳台容不下完整菜园;「无种菜意愿做不出来」。

相关风格 / Related Styles

农庄庭园Farmhouse Garden
现代农庄是农庄庭园的「现代化版本」。差异:农庄「乡土感强」(木板栅/旧物);现代农庄「现代感强」(清水混凝土/耐候钢)。
生态自然主义庭院Ecological Naturalistic Garden
同体系兄弟,都生态导向。差异:现代农庄「实用产出 + 现代美学」;生态自然「无产出 + 草本群落」。
自然主义庭院Naturalistic Garden
都用多年生草本。差异:现代农庄「菜+草本」(实用);自然主义「纯草本」(观赏)。
现代庭院Modern Garden
同属现代主义。差异:现代庭院「建筑师骨架,无生产」;现代农庄「实用生产 + 现代骨架」。
