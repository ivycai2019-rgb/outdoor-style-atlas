风格简介 / Introduction

中国传统院落的现代版本——保留"院落 + 围合 + 借景"的骨架,剥离雕花繁饰,用白墙、青砖、月洞与克制水石把"东方"留在气质里,而不是符号里。

核心气质
克制、留白、可独处。介于中式与极简之间,几乎无装饰。
起源 / 背景
由苏式园林、北方四合院、岭南天井的院落基因,经现代主义重构而成,2000 年后逐渐成型。
室内衔接
与新中式、Japandi、现代极简室内可无缝衔接,色调、材料、留白节奏一脉相承。
— 04

风格识别点 / How to Recognize

在图片或案例中快速判断
01
白墙作底——大面积留白墙体作为整个庭院的视觉画布,而不是装饰背景。墙本身就是主角之一。
02
点景树孤植——单株罗汉松、鸡爪槭或姿态型乔木被刻意孤植,强调姿态而非花量。
03
几何洞口——月洞门、矩形漏窗等几何开口在墙上构成框景,但不带雕花——这是与传统中式的关键分界。
04
静水或水钵——水以静态、克制的形式出现(镜池、水钵、跌水),常配孤石与竹影,几乎不见喷泉或大面积水面。
05
极低饱和的几何线条——青砖、青石板、火烧面石材构成的硬质铺装,边线干净、无纹样图案,与白墙形成画面感构图。
— 05

核心特征 / Core Features

空间结构
围合内院 + 主厅借景 + 偏院与廊道串联。常见"前院 / 主院 / 后院"三段式,主院承担观赏与社交,后院承担私密与冥想。
动线关系
游园式弯折路径 + 直线主轴混合。常通过月洞门、景墙、植物遮挡实现"步移景异",避免一眼看穿。
植物语言
植物气质以姿态型乔木、清雅竹类、低矮地被和少量季相植物为主,花卉用量极克制。
代表植物罗汉松 · 鸡爪槭 · 紫竹 · 苔藓 · 石菖蒲
水景关系
偏静水、浅水、镜面水景,常与白墙、孤石、竹影形成安静画面;不强调喷泉与复杂流水,水钵、跌水、镜池是典型形式。
光影氛围
依赖白墙树影、竹影、廊下阴影与低位暖光,白天安静,夜晚克制,不追求强烈戏剧化。
色彩系统
白 / 灰 / 黑 / 木色 / 苔藓绿。整体低饱和,只在植物季相变化(枫红、竹青)中允许一点彩色介入。
材料系统
青砖、白色灰泥墙、青石板、芝麻黑火烧面、原木、竹、夯土。当代版常加入清水混凝土与黑色钢板。
休闲与活动
主要活动独处冥想 · 户外茶席 · 阅读 · 小型雅集
推荐场景月下饮茶 · 雨季观竹 · 雪日赏枫 · 庭院读书
生活方式慢节奏 · 私人化 · 重视精神空间,客流量小但停留时间长
— 06

相关风格 / Related Styles

用于横向判断与边界划分
侘寂庭院 Wabi-Sabi Garden
相似:都强调留白、低饱和、精神性。
差异:侘寂彻底放弃符号,只剩"残石+苔藓+老木"的氛围;新中式仍保留竹、月洞、白墙等可识别东方符号。侘寂更难落地,新中式更易家用。
日式庭院 Japanese Garden
相似:精神性 + 围合 + 同源植物语汇。
差异:日式更强调"自然抽象化"(踏石、灯笼、池岛),仪式感外显;新中式更强调"墙与门"的人工边界,更书卷气、更克制。
现代禅意庭院 Contemporary Zen Garden
相似:气质同源,几乎是同一象限。
差异:现代禅意更倾向材料抽象(混凝土+水+单一植物),符号比新中式更少;新中式仍保留中国本土植物与砖石,文化指向更明确。
中式庭院(传统) Chinese Courtyard Garden
相似:院落骨架与植物语汇一致。
差异:传统中式有雕花、彩绘、博古架与繁复木构,新中式剥离了这些,只留几何与材料。若与现代室内搭配,几乎只能选新中式。
— 07

适配性 / Suitability

SUITABLE SPACE · 适合空间
小庭院 中庭院 内院 下沉院
不适合超大尺度(会显空),也不适合纯露台/屋顶(缺墙体围合)。最佳尺度 80–300 ㎡。
SUITABLE CLIMATE · 适合气候
温带 亚热带 海边 山地
华北可做,但需考虑冬季常绿植物的耐寒替换。华南需关注通风以避免青砖与白墙泛绿。
MAINTENANCE · 维护难度
中
需定期修剪松枝与竹类、清扫落叶、清理水钵青苔。无大草坪与花境,负担低于英式乡村,高于砾石庭院。
CORE MATERIALS & PLANTS · 代表材料与植物
核心材料白色灰泥墙 · 青砖 · 青石板 · 火烧面石材 · 原木
核心植物罗汉松 · 鸡爪槭 · 紫竹 · 苔藓 · 石菖蒲
UNFIT SCENARIOS · 不适配场景
超大尺度庄园 露台 / 屋顶 儿童活动主导 欧式古典室内 明艳热带配色
超大尺度会消解新中式的"内向围合"气质;露台/屋顶缺墙体支撑会失去骨架;若室内是欧式或地中海风格,室外会形成气质断裂;雕花门头、博古架、彩绘梁柱会把新中式拉回"中式装修化的庭院"。
